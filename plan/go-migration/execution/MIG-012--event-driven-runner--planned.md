# MIG-012 · 이벤트 기반 실행기와 복구

선행 MIG-001 계약. 전용 경로 `backend/internal/runner/`. 저장 및 AI 포트를 가짜 구현으로 주입한다.

1. 글마다 한 전이를 선점한다. 서로 다른 글은 전역 동시 실행 상한 안에서 실행한다. 승인된 시각자료 묶음은 하위 작업도 같은 전역 상한에 포함하고, 새 세션과 재사용 세션·대기 큐 각각의 자원 상한을 명세에 둔다. 글별 대기열에는 글 ID를 중복 적재하지 않는다. 부모 묶음은 자식 작업용 실행 슬롯을 점유하지 않으며, 중단 시 새 자식 예약을 차단하고 실행 중인 자식의 종료를 확인한다.
2. 원격 호출 전에 실행 의도와 안정적인 작업 키를 저장하고, 확인한 원격 ID/턴을 결합한다. 타임라인·상태 이벤트로 깨우되 해당 agent·turn의 결과를 재조회한 뒤 버전 확인과 결과 적용을 한 번만 수행한다. 이미 있는 결과는 예산을 다시 차감하지 않는다.
3. 연결 복구와 재시작에서 영속 대기 작업을 찾아 현재 상태를 대조한다. 응답 유실이나 epoch 변경으로 기존 전송 여부가 불확실하면 확인 대기로 둔다. 큐 포화 시 요청을 영속 보존하고 빈자리가 생기면 진행한다. 재조회는 누락 복구용으로 간격·횟수를 제한한다.
4. 중단·시간 초과·종료 시 `context`로 로컬 구독을 해제하고, 원격 Cancel 후 실제 상태를 확인한다. 완료와 중단이 겹치면 현행 정책대로 한 번만 반영한다. 사용자의 승인·보완을 기다리는 상태는 다음 호출을 예약하지 않는다.

완료 기준: 제어 가능한 이벤트와 가짜 시계로 중복 이벤트, 시작 전후 크래시, 작업 결과 저장 전후 재시작, 일시 정지와 완료 경합, 상한에 도달한 시각자료 묶음을 재현한다. SSE 연결 0건에서도 진행하며 유실 이벤트를 재조회로 회수한다. 종료 후 워커·구독이 회수된다.

최소 실행: `go -C backend test ./internal/runner/...`와 경합·해제 사례의 `go -C backend test -race ./internal/runner/...`. 명령은 해당 패키지 구현 후 사용한다.

검증: FLOW-001, EDIT-001, LIVE-001, ADR-0015.
