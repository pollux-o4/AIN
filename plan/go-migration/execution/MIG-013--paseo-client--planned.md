# MIG-013 · Go Paseo WebSocket 클라이언트

선행 MIG-001 계약. 합성 서버로 구현부터 시작한다. 실제 호환 판정은 MIG-002 이후다. 전용 경로 `backend/internal/paseowire/`.

1. 설정·인증·버전 오류, 읽기/쓰기 수명, 요청별 상관 ID와 응답 한도를 구현한다. 프로토콜 메시지 인코딩과 로컬 자격증명 읽기를 전송 모듈 안에 둔다.
2. 생성·추가 턴·조회·구독, 모델/사고 단계, 중지·보관·제공자 조회를 포트에 연결한다. 수신 이벤트를 기억할 상한과 느린 구독자 처리 방식을 정한다.
3. 재접속에는 bounded backoff를 적용하고, 재구독 시 스냅샷과 cursor/epoch를 호출자에게 전달한다. 연결 종료 때 대기 요청을 해제하고 발송 여부가 불확실한 오류를 구분한다.

완료 기준: 합성 WebSocket에서 인증 거절, 응답 순서 변경, 메시지 유실, 구독 해제, 연결 종료, 오래된 이벤트를 재현한다. 운영 인스턴스는 변경하지 않으며 공통 데몬의 비용 없는 조회로 지원 버전·인증·제공자 목록을 확인한다. 필수 동작 확인이 어려우면 MIG-052에 차단 조건을 인계한다.

최소 실행: `go -C backend test ./internal/paseowire/...`와 경합·해제 사례의 `go -C backend test -race ./internal/paseowire/...`. 명령은 해당 패키지 구현 후 사용한다.

검증: LIVE-001, ARCH-001, OPS-003.
