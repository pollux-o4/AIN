# MIG-014 · Paseo 세션 재사용·정리

선행 MIG-001 계약. 전용 경로 `backend/internal/sessions/`. 가짜 Paseo 포트로 시작한다.

1. 역할별 세션 재사용, 모델·사고 단계 선택, worker 등록·해제를 이식한다. 현재 턴의 epoch·순번·사용량 기준을 저장하고 이전 결과를 새 결과로 집계하지 않는다.
2. 응답·툴 활동을 읽기 전용 스냅샷으로 변환한다. LIVE-001의 공개 필드와 크기 제한을 적용하고 UI에서 구독이 사라져도 실행은 유지한다.
3. 소유 표시, 유휴와 총량 상한, 결과 회수 유예, 정리 재시도 정책을 이식한다. 이전 `source: ain-n8n` 세션은 저장된 소유와 확실히 대응되는 경우에만 인수한다. 공용 데몬의 다른 프로젝트 세션은 보존한다.

완료 기준: 가짜 시계로 유휴 상한과 정리를 검증하고, 재접속·절전 복귀·정상 및 비정상 종료 뒤 같은 작업에 재연결할 수 있다. 작업자 수와 대기 세션 수가 상한 이내로 수렴하고, 취소 응답만으로 중단 완료를 표시하지 않는다.

최소 실행: `go -C backend test ./internal/sessions/...`와 경합·해제 사례의 `go -C backend test -race ./internal/sessions/...`. 명령은 해당 패키지 구현 후 사용한다.

검증: ADR-0013, ADR-0015, LIVE-001, OPS-003.
