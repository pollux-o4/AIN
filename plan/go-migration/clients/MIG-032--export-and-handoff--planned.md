# MIG-032 · 미리보기·내보내기·파일 인계

선행 MIG-001 계약. 전용 경로 `backend/internal/artifacts/`.

1. 글 미리보기 HTML, 회차별 TXT, HTML·ZIP과 그림 다운로드의 파일명·형식·본문을 이식한다. 마크다운 렌더러 차이는 기준 산출물로 확인한다.
2. 그림 조회의 회차 격리와 정지/움직임 선택을 이식한다. 아티팩트 읽기는 저장된 식별자로 제한하고 검증한 경로와 MIME으로 제공한다.
3. 현재 발행 준비 승인 회차의 outbox 인계를 이식한다. 임시 파일과 원자적 완료 절차를 쓰며 동일 인계를 반복하면 같은 결과를 반환한다.

완료 기준: 기존 TXT/HTML·ZIP fixture에서 본문·헤더·구성 파일·인계 내용이 일치한다. 승인 전 인계, 경로 이탈, 일부 쓰기 실패에서 완료로 표시하지 않는다. 외부 발행은 인계 후 별도 작업으로 남는다.

최소 실행: `go -C backend test ./internal/artifacts/...`. 명령은 해당 패키지 구현 후 사용한다.

검증: AIN-API-001, FIGURE-001, ADR-0012, ADR-0028.
