# MIG-021 · 글쓰기 전이·검토·승인

선행 MIG-001 계약. 전용 경로 `backend/internal/writing/`. 시각자료 분기 포트와 시각·ID는 주입한다.

1. `machine`의 필수 작성 단계와 순서, 회차, 계획 검사, 글 상태·명령 허용 규칙을 이식한다.
2. 요구사항 원장·이전 요청 구조, 분량·구간 계약, 표시 수정과 해석 검토·보완·재작성 전이를 이식한다.
3. 사람이 하는 만족·발행 준비 승인과 에이전트 권한·연속 수정 한도를 이식한다. 전이에는 파일/네트워크 처리 대신 다음 action과 의도를 반환한다.

완료 기준: 기존 상태 전이 fixture에 같은 입력을 주면 상태·다음 action·오류가 일치한다. 잘못된 단계·낡은 버전·중복 이벤트에 후속 상태 변경이 발생하지 않는다.

최소 실행: `go -C backend test ./internal/writing/...`. 명령은 해당 패키지 구현 후 사용한다.

검증: FLOW-001, FLOW-002, EDIT-001, AGENT-001, ADR-0016, ADR-0018.
