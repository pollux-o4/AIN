# MIG-022 · 시각자료 배치·선택·승인

선행 MIG-001 계약. 전용 경로 `backend/internal/figuredomain/`. 글 도메인과의 호출은 확정 포트로 격리한다.

1. 범위·배치·후보·사람 선택·구성 승인·수정·삭제 전이를 이식한다.
2. 회차와 그림 번호, 그림별 진행·부분 실패, 후속 재요청 규칙을 고정한다. 표시 기준과 사용자 선택을 구분한다.
3. 그림 묶음에서는 부모 결과와 필요한 하위 결과를 대조한다. 동시 실행 수와 원격 호출은 실행기 포트를 통해 제어한다.

완료 기준: 기존 그림·회차·선택 fixture에서 같은 다음 action을 반환한다. 이전 회차 결과, 다른 그림 결과, 하위 결과 유실로 승인이나 저장이 앞당겨지지 않는다.

최소 실행: `go -C backend test ./internal/figuredomain/...`. 명령은 해당 패키지 구현 후 사용한다.

검증: FIGURE-001, FIGURE-002, ADR-0017, ADR-0026, ADR-0030.
