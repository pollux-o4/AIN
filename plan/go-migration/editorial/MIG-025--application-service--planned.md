# MIG-025 · 편집 서비스와 조회 모델

선행 MIG-001 계약. 전용 경로 `backend/internal/editorial/`. 편집·저장·실행·내보내기 인터페이스를 주입한다.

1. 생성·조회·작업 명령·보관·복원을 이식한다. request ID와 operation ID·expectedVersion을 쓰는 명령의 응답과 권한을 기존 계약에 맞춘다. 글 순서와 승인 정책은 도메인에 둔다.
2. `View`, 이력, 사용량, 산출물 목록·가용 동작을 계산한다. 목록은 필요한 요약만 조회하고 큰 글 본문은 해당 글을 열 때 읽는다.
3. 변경 커밋 후 실행기에 깨우기 신호를 준다. SSE에는 사용자에게 공개할 읽기 전용 활동을 노출한다. 서버 상태로부터 화면에 보여 줄 준비·대기·실패 정보를 구성한다.

완료 기준: 기존 서비스·이력·사용량 fixture에서 오류와 응답이 일치한다. 저장 실패 후 실행 신호가 나가지 않으며, 커밋 직후 재시작한 작업은 복구에 포함된다. UI/CLI 없이 가짜 포트로 검증한다.

최소 실행: `go -C backend test ./internal/editorial/...`. 명령은 해당 패키지 구현 후 사용한다.

검증: AIN-API-001, EDIT-001, EDIT-002, LIVE-001, HISTORY-001, AGENT-001.
