# MIG-024 · 시각자료 생성·검증

선행 MIG-001 계약. 전용 경로 `backend/internal/figureai/`.

1. 시각자료 단계 프롬프트, 모델·렌더 경로 선택과 파일 산출물 규칙을 이식한다.
2. 합성 SVG·이미지로 구조·크기·외부 참조·파일 경로 검증과 정지판 동작을 확인한다. 파일 도구가 필요하면 배포 운영 의존인지 검증 전용인지 명시한다.
3. 결과 묶음의 그림 ID·부모 작업·회차를 대조한다. 완료 전 임시 파일과 부분 실패의 처리 경계를 저장·실행 포트로 전달한다.

완료 기준: 기존 렌더 경로·그림 파일·SVG·모션 fixture와 호환된다. 잘못된 파일과 다른 작업의 산출물을 가져오지 않으며 실행 중 Node 상주 의존 없이 동작한다.

최소 실행: `go -C backend test ./internal/figureai/...`. 명령은 해당 패키지 구현 후 사용한다.

검증: FIGURE-001, FIGURE-002, ADR-0027, ADR-0028.
