# MIG-023 · 작성 프롬프트·결과 계약

선행 MIG-001 계약. 전용 경로 `backend/internal/writingai/`.

1. 역할·문맥·턴 템플릿, 글쓰기에 필요한 입력 선택과 재사용 턴의 delta를 이식한다. 그림 프롬프트는 그림 담당 포트로 둔다.
2. 출력 블록·JSON·필드 검증, 한글 문자 수·구간·요구사항 대조, 검토 판단 집계를 이식한다. 의미 판단은 현행 검토 결과를 사용한다.
3. JS와 Go 문자열 길이·개행·공백·인코딩 차이를 기존 스냅샷과 대조한다. 모델 호출 없이 대표 프롬프트와 구조화 결과를 검증한다.

완료 기준: 정상·부분·잘못된 모델 결과의 파싱과 이벤트 생성이 기준 fixture와 일치한다. 프롬프트·원문·모델 원문은 진단 로그에 포함하지 않는다.

최소 실행: `go -C backend test ./internal/writingai/...`. 명령은 해당 패키지 구현 후 사용한다.

검증: JUDGE-001, FLOW-001, ADR-0013, ADR-0020.
