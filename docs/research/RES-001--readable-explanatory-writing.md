# RES-001 · 읽기 쉬운 설명 글 · 조사 개요

- 기준일: 2026-11-10 · 상태: 조사 결과 · 구현 미적용
- 질문: 좋은 글쓰기 원칙의 공통점 · 정처기 감자 글이 읽기 편한 이유 · AIN 편집 단계 반영 방법
- 역할: 질문·결론·하위 문서 지도만 유지 · 세부 근거·측정·설계는 하위 문서가 원본

## 하위 문서

| --- | --- | --- |

| RES-003 | 정처기 감자 코퍼스 측정 · 작성 방식 · 템플릿·장치 · 약점 | 사이트 재관찰 |

- 의존 방향: RES-002 → RES-003·RES-004 → RES-005 · 하위 문서는 상위·형제를 역참조하지 않음 (P1~P6 태그만 공유)

## 결론

- 감자 글이 읽기 편한 이유는 개인의 문장력보다 **반복 개선된 템플릿 + AI 공동 작성 + 독자 혼동 보정 루프**다. 2026-02 도입 템플릿이 이후 글 대부분에 적용, 2025년 글에는 없음 (RES-003).
- 템플릿 핵심: 지도 먼저 → 독자 수준별 분할 → 글 전체를 관통하는 비유 하나 → 흔한 오해 직접 반박 → 수치로 따라가는 예제 → 스스로 꺼내 보기.
- 연구 근거가 가장 강한 장치: 오해 반박 · 인출 연습 · 독자 수준별 조절 · 대화체 (RES-002).
- AI 반영 방향: 새 단계 없이 기존 산출물에 독자 수준·오해·비유 체계·구간 설계 카드를 더하고, 측정은 코드로, 피드백은 혼동 지점 단위로 운영 (RES-005).

## 공통 한계

- 독자 대상 실험 없음 · "읽기 편함"의 인과는 관찰 + 문헌 기반 가설
- 문서별 한계·미결정은 각 하위 문서에 기록
