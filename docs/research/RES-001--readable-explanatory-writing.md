# RES-001 · 읽기 쉬운 설명 글 조사 개요

- 기준일은 2026-11-10이고, 상태는 조사 결과(구현 미적용)이다.
- 핵심 질문은 좋은 글쓰기 원칙의 공통점이 무엇인지, 정처기 감자 글이 왜 읽기 편한지, 이를 AIN 편집 단계에 어떻게 반영할지이다.
- 이 문서는 질문, 결론, 하위 문서 안내만 둔다. 세부 근거와 측정, 설계는 각 하위 문서를 원본으로 삼는다.

## 하위 문서

| ID | 관심사 | 변경 이유 |
| --- | --- | --- |
| RES-002 | 글쓰기·학습과학 근거, 확인 수준 A/B/C, 원칙 P1~P6 정의 | 출처 추가와 원문 대조 |
| RES-003 | 정처기 감자 코퍼스 측정, 작성 방식, 템플릿·장치와 약점 | 사이트 재관찰 |
| RES-004 | 도구 독립적 설명 글 설계 절차와 장르 경계 | 작성 방법론 수정 |
| RES-005 | AIN 8단계 산출물, 지표, 규칙, 피드백 루프와 검증 제안 | AIN 계약 변경 |

- 문서 간 의존 방향은 RES-002 → RES-003·RES-004 → RES-005이다. 하위 문서는 상위 문서나 형제 문서를 역참조하지 않으며 P1~P6 분류 태그만 공유한다.

## 결론

- 정처기 감자 글이 읽기 편한 이유는 개인의 문장력보다 **반복 개선된 템플릿, AI 공동 작성, 독자 혼동 보정 루프**에 있다. 2026-02에 도입된 템플릿이 이후 글 대부분에 적용되었으나 2025년 글에는 없다(RES-003).
- 템플릿은 전체 개요 먼저 제시 → 독자 수준별 분할 → 글 전체를 관통하는 단일 비유 → 흔한 오해 직접 반박 → 수치로 따라가는 예제 → 스스로 인출해 보기 순으로 짜여 있다.
- 연구 근거가 가장 강한 장치는 오해 반박, 인출 연습, 독자 수준별 조절, 대화체이다(RES-002).
- AI 반영 방향은 새 단계를 추가하지 않고 기존 산출물에 독자 수준, 오해, 비유 체계, 구간 카드를 더하는 것이다. 측정은 코드로 하고 피드백은 혼동 지점 단위로 다룬다(RES-005).

## 공통 한계

- 독자 대상 실험은 하지 않았으며, "읽기 편함"의 인과는 관찰과 문헌을 바탕으로 세운 가설이다.
- 문서별 한계와 미결정 사항은 각 하위 문서에 기록한다.
