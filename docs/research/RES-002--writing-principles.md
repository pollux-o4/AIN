# RES-002 · 좋은 글쓰기 원칙 · 근거

- 관심사: 글쓰기·학습과학 근거 수집 · 공통 원칙 P1~P6 정의 · 근거 확인 수준
- 변경 이유: 출처 추가·원문 대조·원칙 수정

## 확인 수준

| 수준 | 의미 | 대상 |

| A 원문 확인 | 브라우저로 원문·초록 직접 읽음 | 감자 사이트·운영자 글·업데이트 로그 · NN/g 2편 · digital.gov 2편 · Diátaxis compass · Roediger&Karpicke 2006 · Kalyuga 외 2003 · McNamara 외 1996 · Tippett 2010 · Mayer 외 2004 |

- 원칙 ID P1~P6: 다른 RES 문서의 분류 태그 · 이 문서가 정의 원본
- C 수준은 인용·수치 없이 요지만 사용 · 반영 결정의 단독 근거로 쓰지 않음
- 독자 대상 실험 없음 · 감자의 "읽기 편함" 인과는 관찰 + 문헌 기반 가설


## 근거

### 원문 확인 근거 (A)

| 출처 | 확인 내용 | 글쓰기 함의 |
| --- | --- | --- |
| NN/g, Inverted Pyramid (Schade 2018) | 가장 중요한 정보를 먼저 · 제목·소제목·문단 첫 문장·문장 첫 단어를 정보로 채움 · 요약·핵심 목록 추가 권장 | 결론·지도 먼저 · 어디서 멈춰도 핵심이 남게 |
| NN/g, F-Shaped Pattern (Pernice 2017, 2026 재검토) | F자 스캔은 서식 없는 "글 벽" + 효율 추구 + 낮은 몰입이 겹칠 때 발생 · layer-cake(제목만 훑기)·spotted·commitment 등 다른 패턴 존재 · 좋은 설계로 F를 막을 수 있음 | 서술형 소제목 · 굵은 핵심 · 목록 · 대부분 독자는 훑는다고 가정 |
| digital.gov Plain Language (Plain Writing Act 2010 기반) | 특정 독자에 맞춰 쓰기가 법적 요구 · 원칙·쓰기·설계·테스트 4축 | 쓰기와 시각 설계를 함께 다룸 |
| digital.gov Test for understanding | 작성 과정 중 조기 테스트 · 최소 2회 반복 · 짧은 글은 paraphrase test(독자가 자기 말로 설명) | 검토 = 독자가 다시 말할 수 있는가 · 반복 수정 전제 |
| Diátaxis compass | 두 질문으로 글 종류 판별: 행동인가 인지인가 · 습득인가 적용인가 → 튜토리얼·How-to·Reference·Explanation | 진단 단계의 구간 분류 질문으로 그대로 사용 가능 |
| Roediger & Karpicke 2006 (Psych Sci) | 5분 뒤엔 반복 학습이 낫지만, 2일·1주 뒤엔 시험 본 쪽이 훨씬 오래 기억 · 반복 학습은 자신감만 높임 | 다시 읽기보다 스스로 꺼내 보게 하는 질문 |
| Kalyuga·Ayres·Chandler·Sweller 2003 (Ed Psych) | 작업기억은 매우 제한적 · 초보에게 효과적인 기법이 숙련자에겐 효과를 잃거나 해가 됨(expertise reversal) | 독자 수준에 따라 설명 밀도를 바꿈 |
| McNamara 외 1996 (Cognition and Instruction) | 사전지식 적은 독자는 응집성 높은 글에서, 많은 독자는 응집성 낮은 글에서 더 깊이 이해 · 차이는 표면 기억보다 상황 모델(추론·문제 해결) 수준에서 나타남 | "쉽게 다 풀어주기"가 모든 독자에게 최선은 아님 · 수준 분기 필요 |
| Tippett 2010 (IJSME) | 오해는 바뀌기 어려움 · 20년 연구 종합: 오해를 명시하고 반박하는 refutation text가 일반 설명문보다 개념 변화를 더 잘 일으킴 | 흔한 오해를 직접 적고 바로잡는 문단 |
| Mayer 외 2004 (J Ed Psych) | 형식체 대신 대화체("the"→"your" 12곳)만 바꿔도 3개 실험에서 전이 점수 향상, 단순 기억은 차이 없음 | 대화체는 이해·응용에 효과 · 장식 아님 |

## 공통 원칙 6가지

| ID | 원칙 | 판단 기준 | 근거 |
| --- | --- | --- | --- |
| P1 | 독자 수준에 맞춤 | 사전지식·모르는 용어·흔한 오해를 쓰기 전에 적었는가 · 수준별 경로가 있는가 | Kalyuga 2003 · McNamara 1996 · Plain Language · Pinker(C) |
| P2 | 지도 먼저 | 첫 화면에 얻을 것과 전체 구조가 보이는가 · 소제목만 읽어도 흐름이 잡히는가 | NN/g 역피라미드·layer-cake · Minto(C) |
| P3 | 하나씩 | 한 문장 한 생각 · 한 구간 한 개념 · 쉬운 것 → 어려운 것 | Sweller 1988 · Mayer 분할 · Plain Language |
| P4 | 구조가 맞는 구체물 | 정의 곁에 그림·예시·비유 · 비유는 관계가 맞는가 · 한계를 말하는가 | Gentner 1983 · Mayer 멀티미디어 · Heath(C) |
| P5 | 오해를 직접 반박 | 흔한 오해를 적고, 왜 틀렸는지·무엇이 맞는지 바로 쓰는가 | Tippett 2010 |
| P6 | 독자가 꺼내 보게 | 본문만으로 답할 수 있는 확인 질문 · 왜 그런지 설명하게 하는가 | Roediger&Karpicke 2006 · Chi 1989 · paraphrase test |

- 문체 원칙(대화체·군더더기 제거)은 P1~P6 전체에 공통으로 적용하는 수단이다 (Mayer 2004 · Zinsser 등 C).
- 충돌 지점: "다 풀어 쓰기"(P1 초보)는 숙련 독자에게 역효과 → 수준 분기나 접기(호기심·FAQ)로 해결. 쉬운 말은 내용 축소가 아니다(Plain Language).
