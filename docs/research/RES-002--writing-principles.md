# RES-002 · 좋은 글쓰기 원칙과 근거

- 이 문서는 글쓰기·학습과학 근거 수집, 공통 원칙 P1~P6 정의, 근거 확인 수준을 다룬다.
- 변경 이유는 출처 추가, 원문 대조, 원칙 수정이다.

## 확인 수준

| 수준 | 의미 | 대상 |
| --- | --- | --- |
| A 원문 확인 | 브라우저로 원문·초록을 직접 읽음 | 감자 사이트, 운영자 글, 업데이트 로그, NN/g 2편, digital.gov 2편, Diátaxis compass, Roediger&Karpicke 2006, Kalyuga 외 2003, McNamara 외 1996, Tippett 2010, Mayer 외 2004 |
| B 서지 확인 | Crossref로 존재·서지를 확인했으나 본문은 미대조 | Sweller 1988, Gentner 1983, Chi 외 1989, Cepeda 외 2006, Mayer *Multimedia Learning* 3판(2020) 신호 원칙 장, 국립국어원 《쉬운 공문서 쓰기 길잡이》(2022, 목차만 확인) |
| C 도서 지식 | 이번 조사에서 원문 미대조 | Zinsser, Strunk&White, Orwell, Pinker, Heath, Minto, 이오덕, 유시민, 강원국, 김정선 |

- 원칙 ID P1~P6은 다른 RES 문서에서 쓰는 분류 태그이며, 이 문서가 정의의 원본이다.
- C 수준 출처는 인용이나 수치 없이 요지만 쓰며, 반영 결정의 단독 근거로 삼지 않는다.
- 독자 대상 실험은 하지 않았으며, 감자 사례의 "읽기 편함" 인과는 관찰과 문헌을 바탕으로 세운 가설이다.

## 근거

### 원문 확인 근거 (A)

| 출처 | 확인 내용 | 글쓰기 함의 |
| --- | --- | --- |
| NN/g, Inverted Pyramid (Schade 2018) | 가장 중요한 정보를 먼저 배치한다. 제목, 소제목, 문단 첫 문장, 문장 첫 단어를 핵심 정보로 채우고 요약과 핵심 목록을 추가하도록 권한다. | 결론과 전체 개요를 먼저 제시하여 어디서 읽기를 멈추더라도 핵심이 남게 한다. |
| NN/g, F-Shaped Pattern (Pernice 2017, 2026 재검토) | F자 스캔은 서식 없는 장문, 효율 추구, 낮은 몰입이 겹칠 때 나타난다. layer-cake(제목만 훑기), spotted, commitment 등 다른 읽기 유형도 있으며, 좋은 설계로 F자 스캔을 방지할 수 있다. | 대부분의 독자는 글을 훑어본다고 가정하고 서술형 소제목, 굵은 핵심어와 목록을 활용한다. |
| digital.gov Plain Language (Plain Writing Act 2010 기반) | 특정 독자에 맞춰 쓰는 것이 법적 요구 사항이며, 원칙, 쓰기, 설계, 테스트의 4축으로 이루어진다. | 글쓰기와 시각 설계를 함께 다룬다. |
| digital.gov Test for understanding | 작성 과정 초기에 테스트하며 최소 2회 반복한다. 짧은 글은 독자가 자기 말로 설명하는 paraphrase test를 활용한다. | 검토 기준은 독자가 내용을 다시 말할 수 있는지 여부이며, 반복 수정을 전제한다. |
| Diátaxis compass | 행동인지 인지인지, 습득인지 적용인지 묻는 두 질문으로 글 종류를 튜토리얼, How-to, Reference, Explanation으로 판별한다. | 진단 단계의 구간 분류 질문으로 그대로 사용한다. |
| Roediger & Karpicke 2006 (Psych Sci) | 5분 뒤에는 반복 학습이 유리하나 2일·1주 뒤에는 시험을 본 쪽이 훨씬 오래 기억한다. 반복 학습은 자신감만 높인다. | 다시 읽기보다 독자가 스스로 떠올려 확인하게 하는 질문을 둔다. |
| Kalyuga·Ayres·Chandler·Sweller 2003 (Ed Psych) | 작업기억은 매우 제한적이다. 초보자에게 효과적인 기법이 숙련자에게는 효과를 잃거나 해가 된다(expertise reversal). | 독자 수준에 따라 설명 밀도를 조절한다. |
| McNamara 외 1996 (Cognition and Instruction) | 사전지식이 적은 독자는 응집성이 높은 글에서, 많은 독자는 응집성이 낮은 글에서 더 깊이 이해한다. 차이는 표면 기억보다 추론·문제 해결 등의 상황 모델 수준에서 나타난다. | 모든 내용을 쉽게 풀어 쓰는 방식이 모든 독자에게 최선은 아니므로 수준 분기가 필요하다. |
| Tippett 2010 (IJSME) | 오해는 바뀌기 어렵다. 20년 연구를 종합한 결과, 오해를 명시하고 반박하는 글(refutation text)이 일반 설명문보다 개념 변화를 더 잘 일으킨다. | 흔한 오해를 직접 적고 바로잡는 문단을 둔다. |
| Mayer 외 2004 (J Ed Psych) | 형식체 대신 대화체("the"→"your" 12곳)만 적용해도 3개 실험에서 전이 점수가 올랐으며, 단순 기억에는 차이가 없었다. | 대화체는 장식이 아니라 이해와 응용에 효과가 있는 수단이다. |

## 공통 원칙 6가지

| ID | 원칙 | 판단 기준 | 근거 |
| --- | --- | --- | --- |
| P1 | 독자 수준에 맞춤 | 쓰기 전에 사전지식, 모르는 용어, 흔한 오해를 적었는지와 수준별 경로를 두었는지 확인한다. | Kalyuga 2003, McNamara 1996, Plain Language, Pinker(C) |
| P2 | 전체 개요 우선 제시 | 첫 화면에서 얻을 것과 전체 구조가 보이는지, 소제목만 읽어도 흐름이 잡히는지 확인한다. | NN/g 역피라미드·layer-cake, Minto(C) |
| P3 | 하나씩 제시 | 한 문장에 한 생각, 한 구간에 한 개념을 담고 쉬운 내용에서 어려운 내용 순으로 전개한다. | Sweller 1988, Mayer 분할, Plain Language |
| P4 | 구조가 맞는 구체물 | 정의 곁에 그림·예시·비유를 두고, 비유의 관계 구조가 맞는지, 한계를 밝혔는지 확인한다. | Gentner 1983, Mayer 멀티미디어, Heath(C) |
| P5 | 오해를 직접 반박 | 흔한 오해를 적고 왜 틀렸는지와 무엇이 맞는지 바로 제시하는지 확인한다. | Tippett 2010 |
| P6 | 독자의 인출 유도 | 본문만으로 답할 수 있는 확인 질문을 두고 왜 그런지 설명하게 하는지 확인한다. | Roediger&Karpicke 2006, Chi 1989, paraphrase test |

- 문체 원칙(대화체와 군더더기 제거)은 P1~P6 전체에 두루 적용하는 수단이다(Mayer 2004, Zinsser 등 C).
- 원칙 사이에 충돌하는 지점도 있다. 초보 독자를 위해 모든 내용을 풀어 쓰는 방식(P1)은 숙련 독자에게 역효과가 나므로 수준 분기나 접기(호기심·FAQ)로 푼다. 쉬운 말 사용은 내용 축소를 뜻하지 않는다(Plain Language).

## 한계

- C 수준 출처는 원문을 대조하지 않았으며, 국립국어원 길잡이는 뷰어가 이미지 기반이어서 목차만 확인하였다.
- Google Scholar는 자동화 차단으로 사용하지 않았으며, 서지는 Crossref에서, 초록은 출판사 페이지에서 확인하였다.
