## 만드는 방식

- 출처: 운영자 합격 후기·업데이트 로그 원문

- 작성자: 비전공 독학 합격자 · 동기는 "책 설명이 빈약해 이해·암기가 어려움"
- AI 공동 작성: 디자인패턴 글들은 "모두 AI와 함께 작성" · 두음법칙 + 이미지 암기법 고안
- 범위 선정: 기출 분석으로 합격에 필요한 최소 범위를 먼저 정함 → 요약 PDF
- 혼동 보정 루프(업데이트 로그 예): "후보키와 대체키의 혼동을 방지"하도록 조건 추가 · "혼동을 주던 수식어 제거" · 단계별 메모리 다이어그램 4개 추가 · 동의어 정답 인정 · 댓글 제보 보상(기프티콘)
- 함의: 품질은 한 번에 잘 쓴 결과가 아니라 **범위 결정 → AI 초안 → 템플릿 → 독자 혼동 보정**을 반복한 결과

## 글 구조

### 템플릿 뼈대

```text
제목 · 읽는 시간 · 작성·수정일 · [전체 LLM용 복사]
요약 (무엇부터 무엇까지, 왜)
첫 문단 정의 + 이 글이 다음 무엇의 바탕인지
(필요 시) 정직한 범위 안내 — "기출은 아직 확인되지 않음 · 흐름 잡는 용도"
핵심 정리 표 — "하나씩 배울 용어를 미리 정리"
구간 × N  [X란? 쌩기초 → 기초 → 심화 / 호기심(선택)]
  그림(일관 비유의 만화) → 캡션 = 한 줄 결론
  정의 → 비유 → 이유
  수치·코드로 따라가는 예제 (단계 번호)
  비교 표 / 헷갈리는 쌍 비교
  주의 상자: 오해 반박 · 동음이의어 구분 · 시험 함정
  접힌 질문(FAQ): "페이지는 기능 단위로 나뉘나요?"
연습 문제 → 정답 공개 전 확인 → 풀이·추천 문제
다음 글로 잇기 · 관련 개념 · 각주(2차 용어)
```

### 장치별 분석

- 대상: 변수 선언(2026-03) · 가상 메모리(2026-09) · PC·모바일 직접 조작

| 장치 | 관찰 | 원칙 |
| --- | --- | --- |
| 지도 먼저 | 요약 + 핵심 정리 표 · "지금은 훑어보기만 해도 괜찮습니다" | P2 |
| 수준 분기 | 쌩기초·기초·심화 배지(구간 제목·목차) · 2026-09엔 선택형 "호기심" 추가 · 심화 전 선수 글 안내 | P1 |
| 정직한 범위 | "가상 메모리 개념 자체를 묻는 기출은 아직 확인되지 않음 → 외우기보다 흐름" | P1·P2 |
| 일관 비유 체계 | 가상 메모리: 책상(RAM)·창고(SSD)·사물함(주소)·장부(페이지 테이블)를 글 끝까지 재사용 · "앞에서 RAM을 사물함에 비유했습니다" | P4 |
| 관계 구조 비유 | "1반과 2반 모두 출석번호 1번 → 같은 번호, 다른 학생" = 논리 주소 겹침의 관계를 그대로 옮김 | P4 |
| 그림 = 상태 변화 | 같은 메모리 상자 틀에서 `???` → 값 · 페이지 부재 6단계 만화 · 그림 번호 = 본문 단계 번호 | P3·P4 |
| 캡션 = 결론 | "번호는 같은 100번지, 실제 칸은 서로 달라요" · alt 텍스트도 장면을 문장으로 설명 | P2 |

| 동음이의어 구분 | 네트워크의 논리·물리 주소·프레임과 메모리 용어는 이름만 같음 | P5 |

| 인출 | 연습 문제 · 정답 공개 전 "채점 없이 공개됩니다" 확인 · 풀이·추천 문제 | P6 |

## 약점·한계

### 약점·대조군

- 2025 이론 글(옵저버 패턴): 배지·핵심 정리 없음 · 긴 정의 문단 · 제목은 "자바스크립트 예제", 요약은 "타입스크립트 코드" → 템플릿 이전 품질 차이가 큼
- 용어 불일치: 변수 선언 글 본문 "속성(attribute)" · 그림 라벨 "필드(field)"
- 광고가 그림·본문 사이를 끊음 · 모바일 핵심 정리 표 예시 열 잘림 · 빨강 주의 상자 다수(경고 피로 가능)

### 한계

- 2편 정밀 + 213편 구조 집계 · 독자 성과 데이터 없음
- AI 공동 작성 범위는 운영자 서술(디자인패턴 글) 외 미확인
- 템플릿 도입 시점과 품질의 관계는 상관 관찰 · 조회수·합격률과의 인과 미측정
