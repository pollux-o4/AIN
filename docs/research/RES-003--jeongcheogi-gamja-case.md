# RES-003 · 정처기 감자 사례 분석

- 이 문서는 실제 사이트 관찰과 측정 결과, 작성 방식, 템플릿·장치, 약점을 다룬다.
- 원칙 태그는 RES-002의 P1~P6을 따른다.
- 변경 이유는 사이트 재관찰과 코퍼스 재측정이다.

## 코퍼스 측정

- 조사 대상은 sitemap 345개 가운데 글 213개이며, 2026-11-10에 브라우저로 수집하였다.

| 묶음 | 글 수 | 난이도 배지 | 핵심 정리 |
| --- | --- | --- | --- |
| 코딩 2025-09 | 2 | 0 | 0 |
| 코딩 2026-02~09 | 106 | 102 | 95 |
| 코딩 2026-10 | 2 | 0 | 0 |
| 이론 2025-01~2026-03 | 76 | 0 | 0 |
| 이론 2026-04~09 | 27 | 27 | 7 |

- 템플릿은 2026-02 코딩 글에서 시작하여 2026-04 이론 글로 확산되었다. 2026-04-24에는 하루에 보안 글 10편 이상이 같은 틀로 게시되었다.
- 코딩·이론 각 30편씩 총 60편 표본(`<p>` 기준)을 측정한 결과, 문단 중앙값은 62~76자, 문장 중앙값은 40~51자, 표 중앙값은 4~5개이며 모든 글에 요약 구간이 있다.
- 측정에는 한계가 있다. SSR HTML 기준이라 클라이언트에서 렌더링하는 연습 문제와 일부 그림이 집계에서 빠질 수 있고, 목록과 표 안의 문장은 문장 길이 집계에서 제외하였다.

## 작성 방식

- 출처는 운영자의 합격 후기와 업데이트 로그 원문이다.
- 작성자는 비전공 독학 합격자이며, 글을 쓰게 된 동기는 "책 설명이 빈약해 이해·암기가 어려움"이다.
- AI와 함께 글을 썼다. 디자인패턴 글들은 "모두 AI와 함께 작성"하였고, 두음법칙과 이미지 암기법도 고안하였다.
- 기출을 분석해 합격에 필요한 최소 범위를 먼저 정하고 요약 PDF를 만들었다.
- 독자가 헷갈리는 부분을 고치는 혼동 보정 루프를 운영하였다. 업데이트 로그에는 "후보키와 대체키의 혼동을 방지"하도록 조건을 더하고 "혼동을 주던 수식어 제거"를 반영한 기록이 있다. 또한 단계별 메모리 다이어그램 4개를 추가하고 동의어 정답을 인정하였으며, 댓글 제보에 기프티콘으로 보상한 내역도 남아 있다.
- 결국 품질은 한 번에 잘 쓴 결과가 아니라 **범위 결정, AI 초안, 템플릿, 독자 혼동 보정**을 반복해 얻은 결과이다.

## 글 구조

### 템플릿 구조

```text
제목 · 읽는 시간 · 작성·수정일 · [전체 LLM용 복사]
요약 (무엇부터 무엇까지, 왜)
첫 문단 정의 + 이 글이 다음 무엇의 바탕인지
(필요 시) 정직한 범위 안내 — "기출은 아직 확인되지 않음 · 흐름 잡는 용도"
핵심 정리 표 — "하나씩 배울 용어를 미리 정리"
구간 × N  [X란? 쌩기초 → 기초 → 심화 / 호기심(선택)]
  그림(일관 비유의 만화) → 캡션 = 한 줄 결론
  정의 → 비유 → 이유
  수치·코드로 따라가는 예제 (단계 번호)
  비교 표 / 헷갈리는 쌍 비교
  주의 상자: 오해 반박 · 동음이의어 구분 · 시험 함정
  접힌 질문(FAQ): "페이지는 기능 단위로 나뉘나요?"
연습 문제 → 정답 공개 전 확인 → 풀이·추천 문제
다음 글로 잇기 · 관련 개념 · 각주(2차 용어)
```

### 장치별 분석

- 변수 선언(2026-03)과 가상 메모리(2026-09) 글을 대상으로 삼아 PC와 모바일에서 직접 조작하며 관찰하였다.

## 약점·한계

### 약점·대조군

- 2025년 이론 글(옵저버 패턴)은 배지와 핵심 정리가 없고 정의 문단이 길며, 제목은 "자바스크립트 예제"인데 요약은 "타입스크립트 코드"로 되어 있어 템플릿 도입 이전과의 품질 차이가 크다.
- 용어 불일치가 관찰되었다. 변수 선언 글 본문에는 "속성(attribute)", 그림 라벨에는 "필드(field)"가 사용되었다.
- 광고가 그림과 본문 사이를 끊고, 모바일 화면에서 핵심 정리 표의 예시 열이 잘리며, 빨강 주의 상자가 여럿 놓여 경고 피로가 생길 수 있다.

### 한계

- 2편을 정밀 분석하고 213편의 구조를 집계하였으나, 독자 성과 데이터는 없다.
- AI 공동 작성 범위는 운영자 서술(디자인패턴 글) 외에는 확인되지 않았다.
- 템플릿 도입 시점과 품질의 관계는 상관 관찰이며, 조회수·합격률과의 인과는 측정하지 않았다.
