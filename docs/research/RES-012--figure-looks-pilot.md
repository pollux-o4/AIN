# RES-012 · 그림 스타일·움직임 파일럿(2026-11-23)

- 조건: 원본 글 dc08d3c0의 자리 f9·f5, 정책 metaphor, 스타일별로 한 브리지에서 동시 생성(`lab:run --looks`).

## 결론

- 스타일 규칙은 공통 계약보다 앞서야 구분된다. 스타일은 자리 선택에서 정한다(ADR-0027).
- 글자 양은 구성의 장면 범위가 정한다. 그림 하나에 관계 하나, 수량은 사물 개수, 글자 10개 이하(코드가 셈).
- 움직임은 원인 → 결과를 단계마다 하나씩 순서대로 나타낼 때 가장 잘 읽힌다. 정지 그림은 전체를 해석해야 하고, 강조를 여러 곳에 옮기거나 전후만 맞바꾸면 무엇이 바뀌었는지 모른다(ADR-0028).
- 한 장 생성은 anatomy 외 스타일에서 3~6분이다. anatomy는 스킬·키트 읽기로 2~10배 느리다.
