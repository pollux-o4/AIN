# 문서 탐색

- architecture: C1 맥락, C2 실행·저장, C3 책임과 코드 탐색 문서를 제공한다.
- decisions: 관심사 폴더(runtime 실행·경계, workflow 편집 흐름·승인, writing 글쓰기 지시·구조, figures 시각자료·내보내기)에 결정을 두며, `--current.md`로 현재 결정을 검색한다.
- specs: behavior(동작 계약), data(용어 TERM-001), quality(품질 기준)로 나누며, 계약 하나에 파일 하나를 둔다.
- operations: OPS 설치·복구 절차와 비공개 데이터 보존 기준을 다룬다.
- research: RES 원칙·사례·전략 조사 결과를 수록하며, 개요는 RES-001에서 확인한다.
- 공통 규칙: 전역 init-rules의 RULE-CORE·ADR·SPEC·TEST·OPS를 적용한다. 용어는 TERM-001을 따른다.
