# 그림 경로 계약 · `FIGURE-002`

- 범위: 선택된 후보 하나를 그림 결과로 만드는 경로 어댑터의 입력·출력·검사. 위치 제안과 화면 흐름은 FIGURE-001, 경로 선택 이유는 ADR-0025가 원본이다.
- 사전 조건: 후보가 사람에게 선택되었고, 위치 제안의 일관성 계약(`style`, `motifs`)이 저장되어 있다(ADR-0022).
- 계층: 상위 계층은 하위 계층의 구현에 의존하지 않는다.

| 계층 | 담당 | 바뀌는 이유 |
| --- | --- | --- |
| L1 그림 결과 | 화면·내려받기·내보내기가 읽는 유일한 형식 | 표시·인계 방식 변경 |
| L2 경로 어댑터 | `image`, `svg` 입출력과 능력 | 모델·도구 교체 |
| L3 경로 내부 | svg는 ADR-0024 단계, image는 모델별 지시문 | 그리는 방법 개선 |

## L1 그림 결과

| 항목 | 의미 | 검증 |
| --- | --- | --- |
| `id` | 후보 id | `FIGURE_ID` |
| `route` | 만든 경로 | `image`·`svg` |
| `files[]` | `{ path, mime, bytes }`. 첫 파일이 본문에 놓인다 | mime은 `image/svg+xml`·`image/png`·`image/webp`. 크기 상한은 mime별로 코드에 둔다 |
| `alt` | 대체 글 | 필수(FIGURE-001 접근성) |
| `caption` | 그림 아래 한 줄 | 선택 |
| `motion` | 움직임이 있는지 | 참이면 첫 프레임만으로 뜻이 통하고 `prefers-reduced-motion`에서 멈춘다(RES-009 원칙 5) |
| `labels[]` | 그림에 있어야 할 글자 `{ text, anchor? }` | 글자 그대로 저장. `anchor`가 있으면 화면이 그림 위에 얹는다 |
| `provenance` | `{ route, adapter, model, ms, tokens, inputHash, checks }` | 작업 기록에서 채운다. 모델이 보고한 값을 쓰지 않는다 |

- 글자 처리 방식은 `labels`의 `anchor` 유무로 구분한다. 그림 안에 글자를 그린 경우에는 `anchor`를 비우고, 확인 단계에서 사람이 글자를 점검한다.

## L2 경로 어댑터

- 형태: `{ id, route, capabilities, render(input, ctx) → 그림 결과 }`.
- `input`(두 경로 공통, 수 KB 이내):
  - 구성 명세: `message`(1문장), `elements[]`(요소마다 본문 인용), `regions`(좌표 없는 영역 배치), `moving[]`(움직일 대상), `labels[]`.
  - `style`과 후보가 가리키는 `motifs`만. 다른 그림의 결과는 넣지 않는다(ADR-0022).
  - 사람 방향(`direction`, ADR-0023).
- `ctx`: 작업 폴더, 취소 신호, 비밀값 조회. 비밀값과 원문은 결과·로그에 남기지 않는다.
- `capabilities`:

| 능력 | 뜻 | 상위의 처리 |
| --- | --- | --- |
| `motion` | 움직임을 만들 수 있다 | 구성에 `moving`이 있어도 거짓이면 정지 그림으로 만든다 |
| `textInImage` | 글자를 그림 안에 정확히 그릴 수 있다 | 거짓이면 `labels`에 `anchor`를 채운다 |
| `partialEdit` | 결과 일부만 고칠 수 있다 | 거짓이면 수정 요청 시 그 그림 전체를 다시 만든다 |
| `maxChecks` | 렌더를 보고 고치는 최대 횟수 | 넘으면 멈추고 실패로 둔다(RES-009 원칙 5) |

- 경로 선택: 유형별 기본 경로 표를 따르되, 사람이 후보에 경로를 지정한 경우에는 그 경로를 따른다. 해당 경로의 어댑터가 없으면 실행하지 않고 실패로 표시하며, 사람에게 알리지 않고 다른 경로로 바꾸지 않는다.
- 재사용: 결과는 `(입력 해시, 어댑터 id, 지시문 버전)` 키로 저장한다. 같은 키가 있으면 다시 호출하지 않는다(RES-009 원칙 4).
- 경로별 검사:
  - svg: `svgIssue` 안전 검사, `<img>` 표시.
  - image: 파일 서명이 mime과 맞는지, 크기 상한.

## 실패 복구

- 어댑터 오류·취소·검사 실패는 그 그림만 실패로 두고 다른 그림은 계속한다. 이어가기는 저장된 결과가 있는 그림을 건너뛴다.
- 실패한 그림은 준비됨으로 표시하지 않는다(FIGURE-001).

## 호환

- 기존 저장 결과의 `svg` 필드는 `route: svg`, `files[0]: image/svg+xml`로 읽는다. 다시 쓰지 않는다.
- 구성 명세가 없는 이전 후보는 `claim`·`scene`을 `message`·`elements`로 옮겨 입력으로 쓴다.

## 완료 기준

- 모든 어댑터가 같은 계약 테스트 한 벌(`figure_002`)을 통과한다: 결과 형식, 능력별 처리, 취소, 재사용, 검사 실패. 외부 모델은 가짜 어댑터로 대신하고 실제 대기를 쓰지 않는다(TIME-001).
- f4 한 장의 경로별 `provenance`(시간·토큰·크기)와 사람 판정이 남는다. 실제 생성은 사용자 허락 뒤에 한다.
- 관련: ADR-0024, ADR-0025, FIGURE-001, JUDGE-001, TIME-001
