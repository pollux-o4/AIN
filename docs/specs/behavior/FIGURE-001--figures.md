# 시각자료 · `FIGURE-001`

- 근거: 초안 확정 뒤 시각자료를 선택 단계로 추가하라는 사용자 결정에 따른다(ADR-0011).
- 진입: 도크의 확인 탭에서 시작하며, 확정 후 '시각자료 추가'와 '발행 준비 승인'을 같은 위계로 배치하고 안내는 두 선택지를 기준으로 작성한다.

| 상태 | 표시·행동 | 보존·완료 근거 |
| --- | --- | --- |
| 초안 확정 | '시각자료 추가' 또는 '발행 준비 승인'(시각자료 없이)을 선택한다. | 추가 동작이 AI 호출임을 버튼 옆에 표시한다. |
| 위치 제안·생성 중 | 실시간 탭과 중단 동작을 표시하고, 단계 진행 표시에 시각자료 단계를 추가한다. 생성 중에는 그림과 층을 표시한다(시각자료 생성 k/N, 초안·내용 다듬기·시각 마감 n/3). | 본문과 TXT 내려받기는 유지하며, 수정 요청은 작업이 끝난 뒤에 받는다. |
| 위치 선택 대기 | 후보(보여줄 주장, 앵커 문장, 구간)를 선택하고 단위 집계(글 단위 n곳 중 m곳에 후보 k개, 부족하면 확인 필요 문구)를 확인한 뒤 'N곳에 만들기' 또는 '시각자료 없이 진행'을 선택한다. | 본문에 없는 문장 후보는 표시하지 않으며, 선택 전에는 생성하지 않는다. 집계할 때는 수만 센다(ADR-0017). 본문 범위를 골라 후보를 직접 추가하고, 모든 후보의 범위를 문장 단위로 조절한다. 직접 추가한 후보만 취소할 수 있다(ADR-0030). |
| 확인 대기 | 본문에 '확인 전' 점선으로 배치하고, 도크에서 미리보기, 본문에서 보기, 포함할 항목 선택, '시각자료 확인'을 제공한다. | 확인 전에는 발행 준비 승인을 할 수 없다. |
| 확인됨 | 본문에 배치하고 SVG 내려받기, 내보내기(TXT·HTML·ZIP, 움직임 멈춤 선택), '발행 준비 승인' 또는 '시각자료 빼기'를 제공한다. | 확인한 시각자료만 승인 대상에 포함한다. |
| 실패·중단 | 멈춘 시각자료 단계와 이어가기 동작을 표시한다. | 준비됨으로 표시하지 않으며, 명시적 재시도 전에는 새 AI 작업을 시작하지 않는다. |

- 본문 불변: 시각자료 유무와 무관하게 본문 HTML과 TXT의 바이트는 같다. 글 수정은 수정 요청으로 처리하며, 수정하면 확정, 시각자료, 승인을 다시 거쳐야 한다.
- 접근성: 체크박스 그룹은 `fieldset`과 `legend`로 구성하고, 시각자료 대체 텍스트(`alt`)는 AI 결과의 필수 항목으로 둔다. 좁은 폭에서는 아래 시트에 주 동작을 고정한다.
- 검증: `editorial/tests/figures`, `paseo/tests/figures`, `test:flow`(격리 n8n), e2e `ai-writing-figure`(PC·모바일, fixture AI)로 검증한다.
- 묶음 인계: 소비처와 무관한 표준 형식(TXT·HTML·ZIP 및 매니페스트)을 사용한다(ADR-0012).
