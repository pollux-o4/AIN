# 실시간 관측 · `LIVE-001`

- 근거: 단계 안에서 어떤 작업과 내용이 진행되는지 확인하고 싶다는 사용자 요청에 따라, 로컬 소유자가 계속 기다릴지 중단할지 판단할 수 있게 한다.
- 선택: '현재 활동·펼쳐진 미리보기·접힌 실행 기록' 구성을 선택한다. 단계만 표시하는 방식은 판단 근거가 부족하고, 원시 JSON과 상시 전체 로그는 읽기 부담이 크다.
- 관측: 공개 응답, 도구 실행 여부, 응답 대기, 결과 확인, 승인 필요 여부를 관측한다. 내부 추론, 사용자 프롬프트, 명령 인자, 도구 원문은 제외한다.
- 진행 기록: AI 설명 문장과 도구 종류·상태(자료 읽기, 명령 실행 등)를 순서대로 표시하고, 결과 JSON은 미리보기로만 제공한다. 제공자 타임라인 한계에 따라 토큰 단위가 아니라 메시지·도구 단위로 갱신하며, 최근 ACTIVITY_STEP_LIMIT개까지 유지한다.
- 단계 기록: 끝난 실행의 진행 기록을 작업에 보존한다. 단계 진행 표시에서 지나간 단계, 진행 중인 단계, 멈춘 단계를 누르면 작업 도크의 '단계 기록'에서 현재 초안의 해당 단계 마지막 실행 기록을 조회한다. 다만 진행 중인 단계는 실시간 탭을 표시하며, 중단한 실행은 기록이 없다.
- 표시: 실제 활동과 마지막 공개 출력 시각을 구분한다. 20초 이상 출력이 없으면 대기·중단 안내를 표시하며, 추정 완료율과 남은 시간은 표시하지 않는다.
- 미리보기: 알려진 산출물 필드만 일반 텍스트로 표시하고 미완성임을 표기한다. 기존 본문, 다운로드, 승인은 검증된 결과만 사용한다.
- 연결: 인증된 동일 출처 SSE를 읽기 전용으로 연결한다. 다시 연결할 때는 현재 Paseo 타임라인 스냅샷을 복원하며, Go 서버는 현재 작업에 연결된 Paseo 세션과 턴을 대조한다. 회차나 연결이 바뀌면 구독을 교체하고 이전 이벤트를 제외한다.
- 복구: 연결이 끊기면 그때까지 받은 출력을 남기고 자동으로 다시 접속한다. 관측에 실패해도 편집 실패로 이어지지 않으며, 조회나 재연결로 AI를 다시 실행하지 않는다.
- 읽기: 미리보기 안쪽만 최신 내용에 맞춰 스크롤을 따라가고, 사용자가 위로 스크롤하면 정지한 뒤 명시적인 따라가기 동작을 제공한다. 페이지의 포커스와 스크롤 위치는 유지한다.
- 폭·키보드: 긴 내용은 줄을 바꾸고 높이를 제한하며 키보드 스크롤을 지원한다. 단계와 상태만 음성으로 안내하고 출력 토큰마다 읽지 않는다.
- 보존: 완료 결과는 기존 저장 정책을 따른다. 미리보기 원문은 별도 로그나 DB에 복제하지 않고 다시 들어올 때 공급자 기록을 조회하며, 제공자의 공개 출력 시점에 따라 표시 간격이 달라진다.
- 한도: ACTIVITY_TEXT_LIMIT와 최근 타임라인 100항목으로 제한하며, 잘림 표시와 전체 단계 결과를 제공한다.
- 검증: Go의 구독 교체 및 해제는 런타임 경합 검사로 확인한다. fixture 공개 응답 스트리밍, 새로고침, 회차 격리, 네트워크 단절, 구독 해제, 인증과 교차 출처를 PC·모바일 환경에서 검증하며, 실제 AI를 추가로 호출하지 않고 관측 동작을 확인한다.
