# PERF-001 · 로컬 Go 실행 성능

- 부하: 같은 호스트와 로그 수준에서 Node+n8n 기준과 Go 후보를 비교한다. 글 한 건과 동시 네 건, 그림 두 장, 250건 × 128 KiB 이력, 복구 대상 네 건을 같은 합성 제공자로 실행한다.
- 완료 지연: 동시 네 건에서 완료 신호부터 SQLite 저장까지 p95가 250ms 이하여야 한다. 신호→확인, 확인→저장, 저장→API 관측은 별도 항목으로 남긴다.
- 유휴 메모리: AIN 서버 측 RSS 중앙값은 Node+n8n 기준의 50% 이하여야 한다. 가능하면 PSS도 기록한다. 공통 Paseo와 실제 제공자의 메모리는 별도 측정한다.
- 정리: 작업 종료 뒤 실행·대기 세션과 구독이 ADR-0015의 상한으로 돌아와야 한다. 합성 비교에서는 명시적 전체 정리 후 세션과 구독이 0개로 돌아오는지 확인한다.
- 검증: MIG-051의 두 런타임 비교 결과에 호스트, 반복 횟수, 데이터 크기와 브라우저 관측을 남긴다. 시간 조건을 일반 단위 테스트에 적용하지 않는다(TIME-001).
