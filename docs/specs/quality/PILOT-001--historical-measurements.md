# PILOT-001 · 과거 AI 파일럿 실측

- 기준일은 2026-10-26이다.
- 역할 분담: 흐름은 n8n이 맡고, AI 실행은 공통 Paseo를 거쳐 Antigravity CLI가 맡는다.
- 모델: `antigravity/gemini-3.8-flash-medium`을 명시한다. 미지정 또는 목록의 첫 번째 모델을 선택하는 것은 금지한다.
- 이전 오류: Argon의 첫 항목을 선택한 뒤 전용 한도를 전체 계정 한도로 잘못 해석한 사례가 있으므로 모델별 오류 범위를 구분한다.

## 1차 · 실행 안정성

- 명령: `mise run ai:pilot`을 사용하며, 별도 n8n SQLite, 별도 포트, 짧은 고정 JSON 요청으로 실행한다.
- 제한: AI 호출은 최대 1회, 요청 기한은 45초, 전체 실행은 75초로 제한하며, 자동 재시도와 대체 모델은 사용하지 않는다.
- 실제 결과: 정상 완료되었고 marker가 일치했으며, 상태 전이 뒤 다음 AI 호출은 예산에 걸려 차단되었다.
- 재전송: 동일 요청을 2회 전송하여 동일한 jobId와 agentId를 반환받았으며, 실제 세션은 1개만 생성되었다.
- 종료: Paseo 에이전트가 idle 상태임을 확인하였으며, TXT와 발행 결과는 생성되지 않았다.
- 실제 사용량: 입력 9,578 토큰, 캐시 입력 0 토큰, 출력 184 토큰이다.
- 근거: `.local/agy-pilot-e2e/run-1guLZ8/report.json` 및 같은 폴더의 비공개 실행 로그이다.
- 토큰 상한: 제공자가 hard cap을 지원하지 않으므로 호출 수와 시간을 강제 제한하고 사용량을 기록하며, 출력은 짧은 형식으로 요청한다.
- 기한 감시: n8n 조회가 중단되면 브리지 watchdog이 Paseo에 stop을 요청한다. 단위 테스트로 1회 중지를 검증하였다.

## 2차 · 결과물

- 주제·독자: 주제는 비대칭키이며, 독자는 암호학 비전문가이다.
- 계획: 입력된 주제와 독자를 다시 정의하지 않고, 명시적 단계 계획(diagnose → draft → review)으로 진행한다.
- 제한: 최대 3회, 요청당 60초, 전체 240초로 제한하며, 자동으로 수정을 반복하지 않는다.
- 산출물: agy 초고, agy 검토, n8n TXT 저장을 거쳐 사용자 판단 대기 상태로 이어진다.
- 검토 기준: 공개키·개인키 역할, 암호화·서명 구분, 공개키 진위 확인, 대칭키와의 협력, 비유의 적용 한계를 기준으로 검토한다.
- 근거: NIST 공개키·비대칭키·전자서명 정의 및 RFC 8446을 근거로 삼는다.
- 독자 과업: 누가 누구의 키로 암호화·복호화하는지, 왜 서명과 다른지, 공개키가 진짜인지 왜 확인해야 하는지에 대한 답을 본문에서 찾는다.
- 평가 구분: 실제 독자의 이해·회상 연구와 AI 검토를 구분하며, 베스트셀러 수준이라고 단정하지 않는다.
- 후속 수정: 사용자가 실제 피드백을 보낸 뒤 라우팅을 거쳐 새 실행의 호출 예산 안에서 진행한다.

## 2차 실제 결과

- 생성 경로: 진단→초고→검토→TXT 1회차 순으로 생성되었다.
- 최초 초고: 60초 기한을 초과하여 stop 후 idle 상태를 확인하였으며, 자동으로 다시 시도하지 않았다.
- 제한 조정: 완료된 진단을 재사용하여 초고와 검토만 120초 제한으로 1회 재시도해 1회차를 저장하였다.
- 발견: AI 검토가 근거 없는 수백 배 표현, 절대 표현, 인증서 필수 조건 일반화를 통과시킨 오류를 발견하였다.
- 테스트 피드백: 위 오류와 읽기 구조에 대한 E2E 입력을 1회 실행하였으며, 실제 사용자 만족 판단과는 구분한다.
- 실제 복귀: route → draft → review 경로로 복귀하여 주제·독자 재정의 없이 2회차 TXT를 생성하였다.
- 상한: 피드백 실행 상한은 최대 4회, 요청당 120초, 전체 420초이며, 실제로는 3회 호출한 뒤 awaiting_user 상태로 끝났다.
- 실제 2차 총 호출: 총 7회 호출 중 6회가 완료되었고 1회는 시간 초과로 중지되었으며, 루프 반복에 의한 추가 실행은 없었다.
- 성공 요청 사용량 합계: 입력 75,720 토큰, 출력 20,679 토큰이다. 중지된 요청의 사용량은 수집되지 않았으며, 이를 0으로 간주하지 않는다.
- 비용 판단: 단계별 새 agy 세션마다 약 1만 토큰의 기본 문맥 부담이 있음을 확인하였으며, 현재 상태가 비용 효율 최적화 기준을 통과했다고 보지는 않는다.
- 구조 개선 확인: 소제목과 짧은 문단 구성, 수신자·작성자 키 역할 분리, 근거 없는 수치 삭제, 인증서 외 확인 방법 제시를 확인하였다.
- 잔여 편집: 서명은 실제 작성자 확정보다 해당 개인키로 서명되었다는 표현이 필요하며, TLS는 인증서 기반 연결 등 적용 조건을 명확히 할 필요가 있다.
- 품질 판정: 초기 초안보다 개선되었으나, 비전문가의 실제 이해·회상 및 베스트셀러 수준에 대한 검증은 하지 않았으며 최종 만족은 승인되지 않았다.
- 원본 근거: `.local/asymmetric-e2e/run-fpRwkz/report.json`(1회차)이다.
- 피드백 근거: `.local/asymmetric-e2e/run-SFwpdY/report.json`(2회차)이다.
- 호출·종료 근거: `.local/asymmetric-e2e/summary.json`이며, 자체 AI 세션의 running 및 initializing 상태가 0개임을 확인하였다.
- TXT 위치: `.local/ai-runtime/exports/b57f9d549392e597878225554d7ab893cb627eb728e1c405d2a3cdf20ea92d58/revision-2.txt`이다.
- 검증 구분: 순수 상태 전이 8개, 연결·예산 보호 11개, fixture 기반 n8n 흐름 13개 과업, 실제 agy E2E로 구분하여 검증하였다.

## 프롬프트 축약

- 변경: 공통 지시를 축약하고 조사·검토 규칙은 해당 단계에만 전달하며, 단계별 선행 산출물을 선별하고 회차 메타데이터 구조는 제외하였다.
- 피드백: 라우팅에는 현재 산출물 한 벌만 전달하고, 재작성에는 직전 대상 산출물만 추가하며, 검토에서는 이전 검토 평가를 제외한다.
- 보존: 원문, 사용자 목표, 현재 피드백, 필요 근거는 보존하고, 전체 이력은 상태 저장소에 보존한다. 도구 금지, 실행 상한, JSON 계약은 유지한다.
- 저장된 동일 상태 기준 문자 수: 라우팅은 10,179자에서 5,621자로, 재작성은 6,775자에서 4,817자로, 검토는 10,946자에서 5,182자로 줄었다.
- 문자 감소율: 각각 45%, 29%, 53%이며, 모델 토큰 실측과는 구분한다. 측정 근거는 `.local/prompt-diet/report.json`이다.
- 검증: 연결·예산·컨텍스트 선택 테스트 14개와 n8n fixture 흐름 13개 과업(`.local/paseo-flow-tests/run-WdYkDg`)을 통과하였다. 다만 실제 AI 추가 호출은 없었으며, 글 품질의 동등성은 검증하지 않았다.
- shortcut: 단계별 agy 새 세션의 기본 문맥 비용은 유지하며, 축약 프롬프트의 실제 사용량을 비교한 뒤 세션 설정 최적화를 재검토한다.
