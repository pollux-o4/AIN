# ADR-0024 · 그림은 구성 → 배치 → 형태 → 렌더 순서로 만들고, 층 사이는 명세로 인계한다

- 범위: svg 경로 내부(FIGURE-002 L3)의 단계를 정한다. 경로 선택은 ADR-0025가 원본이다.
- 맥락:
  - 측정 기준은 RES-009에 있다. 2026-11-18 기준 그림 한 장에 약 25분, 1천만 토큰, 330KB가 들었다.
  - 2·3층은 장면 원본 없이 완성 SVG만 받는다. 층마다 `/anatomy` 스킬 전체(참고 문서 340KB, 부품 40~80개, 렌더 점검 반복)를 새로 수행한다.
  - 자체 시험에서는 좌표부터 정한 탓에 같은 f4를 세 번 다시 그렸다. 위치 제안 scene의 소재를 모두 그리면 요소를 다 담은 그림이 되었고, 덜어내기만 하면 메시지(명확함)가 사라졌다.
- 대안:
  - A. 현행 유지(층마다 완성 SVG 수정): 비용과 혼잡의 원인을 그대로 둔다.
  - B. 모델이 좌표가 든 장면 JSON을 쓰고 코드가 렌더: 크기는 줄지만 배치 실패(대각선 흐름, 라벨 겹침)가 남는다. 파일럿 1~3차에서 확인하였다.
  - C. 의미 구성은 모델이, 좌표는 코드가 맡는 단계 분리: RES-009 원칙 1·2·4와 맞는다. 선택하였다.
  - D. 솔버로 좌표 최적화: 흐름·비교·순환 유형에는 과하다. 템플릿으로 부족한 사례가 생기면 재검토한다.
- 선택(C):
  - 단계와 담당:

    | 단계 | 담당 | 산출물 |
    | --- | --- | --- |
    | 구성 | 모델 | 메시지 한 문장, 유형(kind), 갈래·단계·끝맺음, 움직일 대상, 요소마다 본문 인용. 좌표는 없다. |
    | 배치 | 코드 | 유형별 템플릿으로 좌표·카메라·라벨 위치를 계산하고, 겹침을 센다. |
    | 형태 | 모델 | 배치가 정한 칸 안에서 대상의 생김새를 부품 어휘로 정한다. 반복 대상은 motifs를 쓴다. |
    | 렌더 | 코드 | anatomy kit으로 SVG를, 키프레임 명세로 CSS 모션을 결정적으로 만든다. |

  - 기존 세 층과의 대응:
    - 초안 층은 구성을 쓴다.
    - 내용 층은 구성을 본문과 대조해 판정한다. 인용이 본문에 그대로 있는지는 코드가 글자로 대조한다(JUDGE-001).
    - 시각 층은 형태와 움직임을 다듬는다.
  - 한 그림 한 메시지:
    - 구성은 claim이 말하는 관계 하나를 다룬다. 그 관계를 이루는 요소(예: 단계마다의 기준, 끝맺음)는 빠짐없이 넣고, 관계에 기여하지 않는 소재는 넣지 않는다. 숫자 상한은 두지 않는다.
    - 위치 제안의 scene도 소재를 나열하지 않고 관계와 필요 요소를 적는다.
  - 움직임:
    - 관계는 되도록 움직임으로 보인다(예: 단계마다 멈췄다 완성에서 끝남, 갈림길에서 되돌아옴).
    - 렌더러는 CSS `offset-path`와 `@keyframes`만 쓰고 스크립트는 쓰지 않는다.
    - 첫 프레임만으로 뜻이 통하게 하고, `prefers-reduced-motion`에서는 멈춘다.
  - 인계와 멱등:
    - 층 사이에는 명세(구성·형태)와 notes만 넘긴다.
    - 층 결과는 `(입력 명세 해시, 층, 지시문 버전)` 키로 저장하고, 같은 키가 있으면 다시 호출하지 않는다.
    - 층끼리는 명세 스키마만 공유한다. kit이 바뀌면 렌더러만 고친다.
  - 스킬과 점검:
    - 지시문은 anatomy 그리기 규칙 가운데 형태에 필요한 것만 싣는다. 스킬 전체 수행과 "부품 40~80개" 기준은 따르지 않는다.
    - 렌더 확인은 층마다 PNG 1~2회로 제한하고, 기하 오류는 배치 코드에서 고친다.
- 이유:
  - 배치를 먼저 계획하면 공간 정확도가 오르고(RES-009 출처 1·2), 좌표를 코드가 맡아야 기하가 맞는다(출처 3).
  - 출력이 길수록 품질과 비용이 함께 나빠진다(출처 4·5).
  - 실무 작업 흐름도 명세를 확정한 뒤 실행하고, 수정을 부분 단위로 한다(출처 8·9).
- 결과:
  - 모델 입출력이 수백 KB에서 수 KB로 줄고, 중단 뒤 재개할 때 같은 층을 다시 계산하지 않는다.
  - 표현력은 배치 템플릿과 부품 어휘로 제한된다. 부족한 유형·부품은 사례가 생길 때 추가한다.
  - 기존 SVG 그림(명세 없음)은 그대로 확인 대상으로 남긴다.
  - 구현 뒤 f1~f4를 다시 만들어 시간·토큰·크기를 RES-009 측정 기준과 비교한다.
