# ADR-0030 · 사람이 본문 범위를 골라 시각자료 자리를 추가하고 범위를 조절한다

- 맥락: 위치 고르기 단계에서 사람이 고를 수 있는 자리는 AI 위치 제안(ADR-0017)이 만든 후보뿐이었다. 후보가 없는 문장에 그림을 두거나, 후보가 설명할 범위(앵커)를 넓히고 좁힐 방법이 없었다(2026-11-25 사용자 요청).
- 선택:
  - 범위 표현: 화면은 렌더링된 글자로 범위를 고르고, 서버는 원문(마크다운) 앵커로 저장한다. 둘을 잇는 규칙은 서버 한 곳이 맡는다.
    - 요청 범위는 W3C Web Annotation의 TextQuoteSelector 모양 `quote: { exact, prefix?, suffix? }`이다. 글자는 렌더링된 평문 기준이며 공백은 연속 공백 하나로 비교한다.
    - 서버는 초안의 평문 투영(인라인 표시 `**`·`*`·`_`·`` ` ``·링크 주소·제목 `#`·목록 표시 제거)에서 `exact`를 찾고 `prefix`·`suffix`로 동률을 가른 뒤, 원문 위치로 되돌려 앵커(원문 부분 문자열)를 만든다(`resolveQuote`).
    - 거부: 찾지 못함(`not_found`), 하나로 정할 수 없음(`ambiguous`), 소제목 경계를 넘음(`crosses_unit`), 다른 후보 범위와 겹침(`overlaps`), 상한 초과(`too_long`, `FIGURE_LIMITS.range`).
    - 화면이 후보 범위를 표시하도록 각 후보에 평문 투영 `quote`를 함께 내려 준다. 투영 규칙을 화면에 다시 두지 않는다.
  - 동작(위치 선택 대기 `awaiting_figure_choice`에서만, AI 호출 없음):
    - `place_figure { quote, claim }`: 사람 후보를 추가한다. `origin: "human"`, id는 비어 있는 가장 작은 `FIGURE_ID`, `claim`은 필수이며 `reason`은 `claim`과 같게 둔다.
    - `place_figure { figure, quote, claim? }`: 기존 후보(AI·사람)의 범위를 바꾼다. `claim`은 사람 후보만 바꿀 수 있다.
    - `remove_figure { figure }`: 사람 후보만 지운다. AI 후보는 고르지 않는 것으로 뺀다.
    - 단위 집계(`coverage`)는 동작마다 다시 센다. 후보 상한(`FIGURE_LIMITS.candidates`)은 사람 후보를 포함한다.
  - 화면:
    - 입력은 브라우저 기본 텍스트 선택을 쓴다. 마우스 끌기·Shift+화살표·터치 선택 손잡이를 그대로 지원하며, 자체 드래그 손잡이를 만들지 않는다.
    - 선택은 문장 경계(`Intl.Segmenter`, granularity `sentence`)로 넓혀 맞춘다. 선택 끝에 떠 있는 동작 「여기에 시각자료」를 보이고, 키보드로도 닿게 한다.
    - 후보 범위는 CSS Custom Highlight API로 표시하고 본문 DOM을 바꾸지 않는다. 카드의 「범위 조절」은 현재 범위를 선택해 두고, 사람이 다시 고른 뒤 「이 범위로」로 확정한다.
    - 사람 후보에는 「직접 추가」를 표시하고 「추가 취소」를 둔다.
- 결과:
  - 사람 후보도 구성·생성·실패 처리 흐름(ADR-0026)을 그대로 탄다.
  - 확정 뒤 그림 추가는 다루지 않는다. 확정된 결과를 다시 여는 흐름이 필요해 별도로 정한다.
- 관련: ADR-0017, ADR-0023, ADR-0026, FIGURE-001
