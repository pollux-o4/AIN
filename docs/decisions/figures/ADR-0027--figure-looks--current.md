# ADR-0027 · 그림 스타일은 그림마다 내용에 맞게 고른다

- 맥락: 생성 수단이 anatomy 아이소메트릭 하나로 고정되어, 절차·관계·개념 정리처럼 평면 도식이 더 빨리 읽히는 자리도 실물 비유 입체로 그렸다.
- 선택:
  - 스타일 목록 `FIGURE_LOOKS`(계약)와 그리기 규칙 `LOOK_RULES`(`paseo/prompts/looks.mjs`)를 같은 id로 둔다: anatomy·sketchnote·tablet·stick·manual.
  - 구성(`figure_compose`)이 기본 스타일 하나를 `style.look`에 적고, 다른 스타일이 더 빨리 읽히는 자리는 그 design의 `look`에 따로 적는다. 그림 한 장의 실제 스타일은 그림별 값이 있으면 그것, 없으면 기본값이다(`lookOf`). 모르는 값은 버리고, 둘 다 없으면 anatomy로 그린다.
  - 일관성(ADR-0022)은 원래 목적에만 적용한다. 같은 대상(motifs)이 나오는 그림끼리는 같은 스타일로 그린다. 같은 대상이 손그림과 입체로 따로 그려지면 독자가 같은 것으로 알아보기 어렵기 때문이다. 같은 대상이 없는 그림끼리는 스타일이 달라도 된다.
  - 2026-11-25 갱신: 처음에는 글 하나에 스타일 하나로 고정하였다. 그러나 ADR-0022가 해결하려던 문제는 같은 대상의 생김새가 어긋나는 것이었고, 글 전체를 한 스타일로 묶을 연구 근거는 없었다. 이 고정 때문에 내용에 맞지 않는 스타일이 글 전체에 걸렸다(REST 편: 조립 설명서 스타일로 추상 개념 9장).
  - 생성 층은 고른 스타일의 그리기·준비·마감 규칙만 받는다. 키트 도구는 anatomy에만 싣는다.
  - anatomy 밖 규칙은 Lemo-Opuscar STYLE.md(CC BY-NC 4.0)에서 영상 문법을 걷어내고 SVG 한 장에 맞게 줄여 옮겼다. 출처는 규칙 파일 머리에 적는다.
- 결과:
  - 사람은 구성 확인 단계와 그림을 만든 뒤 모두 그림마다 스타일을 바꿀 수 있다. 바꾸면 그 자리만 다시 구성하고 다시 그린다. 의견 없이 스타일만 바꿀 수 있다.
    - 사람이 고른 값은 `lookBy: "user"`로 남기고, 다시 구성해도 구성이 덮어쓰지 않는다. 처음 자리를 고를 때(`select_figures`)는 지난 회차 값을 지운다.
    - 화면은 같은 대상이 나오는 다른 그림을 함께 바꿀지 묻고, 기본은 함께 바꾸기다.
    - 부분 고치기(`fix`)는 직전 그림을 고치는 일이므로 스타일을 바꾸지 않는다.
  - 손글씨 글자는 미룬다(글꼴을 SVG 안에 넣는 도구 필요, 규칙 파일의 shortcut).
  - 블로그가 수익을 내면 CC BY-NC 범위를 다시 확인한다.
- 관련: ADR-0011, ADR-0022, ADR-0026, FIGURE-001
