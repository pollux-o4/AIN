# ADR-0028 · 그림 움직임은 원인 → 결과를 순서대로 재현하는 한 주기 루프로 만든다

- 맥락: 정지 그림은 전체를 해석해야 하고, 강조를 여러 곳에 옮기거나 전후만 맞바꾸면 무엇이 바뀌었는지 읽히지 않았다. 단계가 순서대로 나타나는 방식이 가장 잘 읽혔다(RES-012).
- 선택:
  - 원인 → 결과를 실제 순서대로, 단계마다 한 동작씩 재현한다. 스타일별 표현은 `LOOK_RULES[].motion`.
  - `<style>` 안 @keyframes 한 주기(6~12초)를 나눠 쓰고, 완료 상태로 머문 뒤 되돌리며, 고정된 장면은 어느 순간에도 사라지지 않는다. 기본 속성은 완료 상태(정지판·RSS·reduced-motion). 초당 3회 초과 깜빡임·스크립트·SMIL 금지.
  - 배치 점검 도구는 정지판으로 배치를 재고 `--frames`로 주기 시점 PNG를 낸다. 움직임 판별은 `contracts/svg-motion.mjs` 하나를 쓴다.
- 관련: ADR-0011, ADR-0027, RES-012
