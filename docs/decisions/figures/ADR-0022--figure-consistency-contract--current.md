# ADR-0022 · 그림 사이 일관성은 위치 제안이 정한 계약으로 맞춘다

- 맥락: 그림은 한 장씩 별도 작업에서 만들고, 각 작업은 다른 그림을 보지 못한다(ADR-0017). 실제 후보 19개를 점검한 결과(2026-11-18), 같은 대상이 여러 그림에 반복해 나왔다(자물쇠 2곳, 명함 묶음 3곳 등). 그런데 대상의 생김새와 강조색·라벨 형식을 정한 기준이 없어 그림마다 다르게 그려질 수 있었다.
- 선택:
  - 그림 작업끼리 서로의 결과를 보여 주지 않는다. 서로 모르는 상태를 유지해야 어긋남이 생겼을 때 계약과 비교해 찾아낼 수 있다(2026-11-18 사용자 결정).
  - 구성(`figure_compose`)이 글 전체와 고른 자리 전부를 보고 계약을 한 번 정한다. 처음에는 위치 제안이 정하였으나 ADR-0026에서 구성 단계로 옮겼다. 일부 자리만 다시 구성할 때는 계약을 바꾸지 않는다.
    - `style`: 모든 그림이 함께 지킬 강조색, 기본 색·선, 라벨 형식.
    - `motifs`: 두 후보 이상에 나오는 대상의 이름(`name`)과 생김새(`look`). 후보는 `motifs`에 이 이름을 글자 그대로 적는다.
  - 코드는 글자 대조와 세기만 한다(JUDGE-001).
    - 이름이 겹치는 대상은 처음 것만 남긴다. 상한은 `FIGURE_LIMITS.motifs`이다.
    - 계약에 없는 이름은 후보에서 뺀다.
    - 실제로 두 후보 이상이 가리키는 대상만 계약에 남긴다.
  - 각 그림 작업은 `style`과, 자기 후보가 가리키는 `motifs`만 받는다.
  - 화면:
    - 후보 계획(구도·비유·이유·반복 대상)은 고르는 단계에서 본문 자리에 펼쳐 보인다.
    - 그림을 만든 뒤에는 계획을 그림 아래에 접어 두고, 필요할 때 펼쳐 결과와 비교한다.
    - 반복 대상에는 같은 대상이 나오는 다른 후보 번호를 함께 표시해, 확인할 때 서로 비교할 그림을 알려 준다.
- 결과:
  - 계약은 선택 항목이다. 계약이 없는 이전 제안도 그대로 진행된다.
  - 계약을 지켰는지는 사람이 확인 단계에서 판정한다. 코드는 판정하지 않는다.
- 관련: ADR-0011, ADR-0017, FIGURE-001, JUDGE-001
