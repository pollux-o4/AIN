# ADR-0023 · 사람이 후보마다 그림 방향을 덧붙인다

- 맥락: 사람이 그림 방향을 줄 수 있는 곳은 시각자료를 요청할 때 쓰는 전체 위치 지시(`placementNote`) 하나뿐이었다. 위치 제안이 세운 계획(구도·비유)을 보고 특정 후보만 다르게 그리게 할 방법이 없었다.
- 선택:
  - 위치를 고를 때 후보마다 방향을 한두 줄 덧붙일 수 있다. 쓰지 않으면 계획대로 만든다.
    - 요청: `select_figures`의 선택 항목 `directions: { [id]: string }`. 상한은 `FIGURE_LIMITS.direction`이다.
    - 저장: 고른 후보에만 `candidate.direction`으로 남긴다. 빈 값과 고르지 않은 후보의 방향은 버린다.
    - 전달: 각 그림 작업은 자기 후보의 방향만 받는다(`candidates[].direction`). 그림 작업끼리 서로 모르는 구조(ADR-0022)는 유지한다.
  - 지시문: 방향은 사람의 지시로 보고 위치 제안의 구도(`scene`·`kind`)보다 먼저 따른다. 다만 본문에 없는 사실·수치를 넣으라는 방향은 따르지 않고, 그 부분과 이유를 `notes`에 적는다.
  - 화면:
    - 고른 후보 자리 아래에 "방향 덧붙이기"를 접어 둔다. 방향을 쓴 후보에는 본문 자리와 도크 목록에 "방향 있음"을 표시한다.
    - 고르기와 방향은 한 상태(`useFigureChoice`)가 맡고, 쓰던 방향은 같은 위치 제안 안에서 새로고침해도 남는다.
    - 만든 그림 아래 접힌 계획 맨 위에 "내 방향"을 보여 계획·방향·결과를 비교하게 한다.
- 결과:
  - 방향을 따랐는지는 사람이 확인 단계에서 판정한다. 코드는 판정하지 않는다(JUDGE-001).
  - 만든 뒤 특정 그림만 다시 만드는 기능은 생성 흐름이 바뀌므로 별도로 정한다.
- 관련: ADR-0011, ADR-0017, ADR-0022, FIGURE-001, JUDGE-001
