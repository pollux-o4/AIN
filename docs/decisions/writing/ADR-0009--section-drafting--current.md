# ADR-0009 · 분량 예산이 있는 초고의 구간별 작성

- 맥락: 구성 예산(4,500자)과 구간별 실측·삭감량을 제시해도 초고 모델이 7~9천 자를 썼고, 전체 일괄 재작성은 요청 제한 120초를 넘어 실패가 반복되었다.
- 대안:
  - 더 강한 모델과 긴 제한 시간을 두는 방안은 모델에 의존한다.
  - 초고 뒤에 한꺼번에 줄이는 방안은 실패가 되풀이된다.
  - 구간 단위 작성(지면 단위 원고) 방안을 함께 검토했다.
- 선택:
  - 분량 요구 또는 구간 budget이 있으면 outline 구간(2~8개)마다 따로 호출한다.
  - 구간 예산의 125%를 넘으면 그 구간만 다시 작성한다(상한은 3회이다. 2회 상한에서는 2,089→1,930→1,810자로 좁혀지다 허용치 60자 앞에서 멈춘 실측이 있었다).
  - 상한을 다 쓴 뒤에도 분량을 넘으면 수용하지 않고 `failed`로 처리하며, 이어가기는 같은 지적으로 재개한다.
  - 완성된 구간을 순서대로 합쳐 draft 산출물 1개를 만든다.
- 구현:
  - `domain/sections.mjs`에서 계획, 수용, 합치기를 담당한다.
  - nextAction에 `section`을 담고, 결과 이벤트의 `section`이 일치하는지 검사한다.
  - 문맥에는 직전 구간과 같은 순서의 이전 구간만 넣는다.
- 예산:
  - 분량 요구가 있으면 코드가 outline 결과를 검사한다. 구간 수가 2~8개인지, 모든 구간에 `budget`이 들어 있는지, 합계가 요구 범위 안인지 확인한다.
  - 어기면 `retryNote`를 넘겨 1회 다시 작성하고, 반복되면 `failed`로 처리한다.
  - 균등 배분 대체 경로는 두지 않는다(예산 누락 구성이 1,650자×3으로 통과해 7천 자대 원고가 된 실측이 있었기 때문이다).
  - 이어지는 구간 호출은 단계 예산에서 제외하고 구간 수 상한으로 제한한다.
- 전체 분량과 묶기(2026-11-15):
  - 구간 한도는 min(예산 125%, 전체 상한 − 이미 쓴 분량 − 남은 구간 예산)으로 계산한다. 마지막 구간은 전체 하한을 채우는 최소 분량도 함께 검사한다.
  - 구간마다 125%를 따로 허용하면 합계가 상한을 넘어 구성부터 다시 쓰던 실측이 있었다(예산 780자 → 917자, 요구 600~900자, 호출 9 → 13~14회).
  - 구간 한도를 지킨 글은 전체 범위를 벗어나지 않으므로, ADR-0007 분량 가드는 구성 뒤에 분량 요구가 바뀐 경우의 후속 검증 장치로 남는다.
- 구조(2026-11-15): 모든 구간은 `## 구간 제목`으로 시작한다(첫 구간은 제목과 도입부 뒤에 온다). 글 분할의 단일 정의는 `contracts/article-structure`에 두며, 첫 구간에 소제목이 없던 이전 초고도 기준본으로 읽는다.
- 도입부 형식(2026-11-17): 원고(구간별 작성인 경우에는 첫 구간)는 `# 구성 제목` 줄로 시작해야 수용하며, 형식만 대조한다. 어긋나면 반려 원고와 사유를 전달해 다시 작성하게 한다(한 번에 쓴 초고도 같다). 구성을 다시 작성한 뒤 제목과 도입부가 없는 원고가 검토 단계까지 넘어간 실측이 있었다.
- 다시 쓰기: 거부된 구간 원고를 기준본으로 제시하고 분량을 줄이는 편집으로 요청한다(처음부터 다시 쓰면 2,556→2,470→2,262자로 거의 줄지 않은 실측이 있었다). 다시 쓰기 상태는 `state.retry` 하나로 관리한다.
- 측정(2026-11-11): 분량은 독자에게 보이는 글자(공백 포함)를 기준으로 재되 마크다운 링크 주소는 제외한다(참고 문헌 URL ~510자가 예산을 차지한 실측이 있었다). 측정 원천은 `domain/length.mjs`의 `readerLength`이다.
- 결과: 호출당 작업량이 작아져 시간 초과가 완화되며, 분량 초과를 구간 단위로 즉시 교정할 수 있다. 다만 분량 예산이 없는 글은 기존처럼 한 번에 작성하므로 추가 비용이 들지 않는다.
- 입력: 의뢰할 때 분량 프리셋(짧게·보통·길게) 또는 CLI `--length`를 입력받으며, 같은 ±10% 규칙(`lengthRange`)을 적용한다.
- 관련: 관련 문서는 ADR-0007, ADR-0008, RES-006이다.
- 시간(2026-11-11): 구간 호출 실측은 96~116초이며 출력 대부분이 사고 토큰이다. 품질 유지를 위해 사고 단계를 유지하고, 요청 상한 300초, 전체 1,800초로 시간을 수용한다(OPS-003).
