# ADR-0006 · 위임받은 에이전트가 편집장 · 최종 검수는 사람

- 맥락: 담당(기획·조사·작성·검토)은 분리됐으나 검토 결과를 보고 되돌릴지 넘길지 판정하는 자리가 없음 · 분량 3배 초안도 "초안 준비됨"으로 사람에게 도달 · AI 내부 자동 피드백 금지 원칙(FLOW-002)
- 대안: AIN 내부 편집장 AI 자동 되돌림 / 담당 간 자유 대화(다중 에이전트) / 위임받은 외부 에이전트가 CLI로 판정
- 선택: 위임받은 에이전트가 편집장 · `feedback`만 허용 · `satisfy`·`authorize_publication`은 사람만
- 이유: 상태 머신은 결정적으로 유지 · 판정 근거가 대화에 남아 사람이 즉시 교정 · 내부 자동 피드백 금지 원칙과 양립 · 자유 대화는 비용·재현성 통제 불가
- 강제(서버): 에이전트 토큰 요청은 actor `agent` · 최종 검수 403 · 사람 행동 없이 연속 에이전트 수정 `EDITORIAL_LIMITS.agentFeedbackRounds`(2)회 초과 409 · 이벤트 `by`·라벨 "편집장 수정 요청"으로 기록
- 판정 근거: 리뷰 findings · 코드 지표 `draftMetrics` · 사용자 요구(idea) · 판정 기준은 스킬 `ain-write`
- 결과: 위임 범위 안 수정은 매회 비용 승인 불필요 · 상한 도달·반복 지적은 사람에게 보고
- 변경: 편집 메모·합격 판정은 AIN 내부로 이동(ADR-0008) · 이 문서는 외부 에이전트의 권한(수정 지시 상한·최종 검수 금지)만 유효
- 관련: ADR-0005 · AGENT-001 · RES-005
