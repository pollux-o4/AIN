# ADR-0005 · 에이전트 접근은 HTTP 계약 위 CLI

- 맥락: 사용자는 주로 대화형 AI와 일함 · AI가 사용자 대신 AIN에 의뢰·수정·삭제해야 함 · 기존 API는 화면 쿠키·동일 출처만 허용
- 대안: 화면 자동 조작 / 별도 기능을 가진 CLI / 화면과 같은 HTTP 계약을 쓰는 얇은 CLI
- 선택: 얇은 CLI + 별도 로컬 에이전트 토큰 · 사용 절차는 스킬
- 이유: 텍스트 결과로 즉시 판단 · 화면 배치 변경에 무관 · 정책이 서버 한 곳에 있어 화면·CLI가 같은 규칙을 따름 · 화면 조작은 느리고 비용·실패가 큼
- 결과: cli 모듈은 contracts만 의존(dependency-cruiser) · 새 기능은 서버 계약에 먼저 추가 · 화면은 사람 관찰·E2E용
- 관련: AGENT-001 · AIN-API-001 · ARCH-001
