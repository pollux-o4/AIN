# ADR-0019 · 지시문은 자연스러운 한국어를 요구하고 문형을 정하지 않는다

- 맥락: 실제 글(알고리즘 입문, 2026-11-17)에 콜론 소제목, 'A가 아니라 B' 굵은 문장, '~하십시오' 닫는 줄, 지도·가로줄·세로줄·칸 비유가 반복되었다. 사용자는 이를 어색한 한국어이며 독자가 머리를 한 번 더 쓰게 만든다고 지적했다.
- 원인(근거): 모델의 기본 문체가 아니라 지시문이었다.
  - 항목 안내의 예시가 글에 그대로 실렸다(예: 소제목 안내의 '이름: 결론' 예시가 실제 소제목 형식이 됨).
  - 항목마다 문형을 정했다(밑줄 = 'A가 아니라 B' 대비, 닫는 줄 = 명령형, explain 글 = 비유 대상 필수). 그래서 모든 구간이 같은 틀로 찍혔다.
  - 지시문의 내부 은유(지도·이름표·칸)가 글의 낱말로 새었다.
- 원칙: 글의 목적은 독자가 머리를 덜 쓰고 바로 알아듣는 것이다. 지시문은 이 목적과 항목의 역할만 정하고 문장 모양은 정하지 않는다.
- 선택:
  - 공통 기준 `NATURAL_KOREAN`(`paseo/seasoning`): 소리 내어 읽어 자연스러운 한국어를 쓴다. 번역투, 문형에 끼워 맞춘 문장, 한 번 더 옮겨 생각해야 하는 추상 비유는 쓰지 않는다. 구성과 초고에 적용하고, 검토 S4 점검 항목에 포함한다.
  - 항목 안내(`contracts/ai-output`): 소제목은 독자가 얻을 답, 밑줄은 기억하기 쉬운 일상어 1문장, 닫는 줄은 preserveVoice 말투의 판단·행동 1문장이다. 문형 지정과 본문에 실릴 수 있는 예시 문장은 두지 않는다.
  - 비유(`analogySystem`): 일상 사물이 개념과 직접 대응할 때만 둔다. 없으면 비유 없이 직접 설명한다(P4).
  - 지시문 낱말: 내부 은유 대신 글에 써도 되는 낱말(구조·명칭·항목·순서 개요)을 쓴다.
  - 구성 단계: 여러 구간의 같은 항목을 같은 문형으로 쓰지 않는다.
- 판정: 자연스러움은 검토(LLM) 점검표로만 본다. 코드는 문형·낱말을 검사하지 않는다(JUDGE-001).
- 관련: ADR-0013 · ADR-0014 · RES-007 · JUDGE-001
