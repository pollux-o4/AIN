# ADR-0004 · 스마트 엔드포인트·얇은 전달 경로

- 맥락: 기본 n8n은 이미 전달·대기지만 기존 고급 워크플로가 도메인·예산을 포함하고 상태 머신 위치도 n8n에 속해 책임이 혼재
- 선택: 편집 도메인·애플리케이션의 단일 정책 경로 · n8n의 도메인 코드 포함·원시 상태 봉투 실행을 제거 · 모든 실행 검증이 같은 편집 모듈 사용
- 모듈: editorial·paseo·n8n·contracts · runtime은 별도 배포 서비스가 아닌 동일 Node 프로세스의 조립 진입점
- 경계: ARCH-001 · 공개 모듈 진입점과 주입 포트 사용 · UI/어댑터의 정책 복제·역방향 참조·순환을 검사기로 차단
- 호환성: 공개 사용자 입력·조회·명령·TXT 다운로드·기존 SQLite·작업 파일 유지 · 이전 내부 /jobs·/exports·/providers HTTP 경로는 410, 제공자 조회는 공통 SDK CLI 사용
- n8n: 기존 기본 workflow ID 유지 · 이전 고급 JSON/생성 정책 제거 · 기존 비공개 실행 증거는 보존
- 검증: 동일 애플리케이션을 단위·격리 n8n·fixture·브라우저·실제 모델로 확인 · 실제 게시 없음
