# ADR-0011 · 시각자료는 초안 확정 뒤 선택 단계 · 본문 불변 배치

- 맥락: 글만으로 전하기 어려운 관계·순서·비교를 보여 줄 시각자료 요구 · 필수 8단계에 넣으면 모든 글에 비용, 본문과 함께 만들면 확정한 글이 다시 바뀜
- 대안: 초고 단계에서 함께 생성(본문·그림 동시 변동, 매번 비용) / 발행 준비 승인 뒤 추가(승인한 결과물과 넘기는 결과물이 달라짐) / 확정과 승인 사이 선택 단계
- 선택(2026-11-12 사용자 결정):
  - 흐름: 초안 확정 → [시각자료 추가 → 시각자료 확인] 또는 [시각자료 없이] → 발행 준비 승인 · 승인 대상 = 본문 + 확인한 시각자료(`approval.figures`)
  - 본문 불변: 시각자료는 앵커 문장이 든 문단 뒤에 배치만 · 초안 확정 유지 · 글을 고치려면 기존 수정 요청(확정·시각자료·승인 무효, 시각자료는 이력에만 보존)
  - 위치: 개념 소개 문단(정의 → 비유 → 결과·한계)마다 그 마지막 문장 뒤 · AI가 후보(앵커 문장+개념·비유 대상·결과를 담은 주장) 제안 → 코드가 본문과 글자 그대로 대조·중복 제거·최대 6개 → 사람이 선택한 것만 생성(AI 호출: 제안 1회 · 생성은 층 수 3회)
  - 인계: 글을 먼저 완성하는 이유는 그림 담당이 글의 의도를 이어받게 하기 위함 · 그림 담당에 글 설계(audience·value·outline)와 본문 전체를 주고, 후보마다 reason(이 지점에서 독자가 깨달아야 할 것)·analogy(본문 비유 대상)·scene(라벨 없이 보이는 원인 → 결과)을 넘긴다 · 생성은 본문 비유 대상을 뜯어 그리고 다른 물건으로 바꾸지 않는다
  - 상태: `waiting_figure`(AI) · `awaiting_figure_choice`(선택 대기) · `awaiting_figure_review`(확인 대기) · 확인하면 `satisfied`+`figure.phase=confirmed` · 준비(후보·생성물)와 사람 확인을 다른 상태·기록으로 구분
  - 형식: SVG 한 요소 · 실행·외부 참조 요소·속성, 주소·이벤트 속성을 바꾸는 애니메이션은 계약에서 거부 · SVG 자체 움직임(SMIL·`<style>` 안 @keyframes)은 허용(2026-11-13): 기본 속성(첫 프레임)만으로 뜻이 통하고 `prefers-reduced-motion`에서 멈춤 · 스크립트 인터랙션·WebGL은 만들지 않음 · 화면은 동일 출처 파일을 `<img>`로만 표시, 파일 응답은 `default-src 'none'; sandbox`
  - 생성: `figure` 단계는 `/anatomy` 스킬 기준으로 층을 나눈 AI 작업 3회(2026-11-13 사용자 결정, f1 교차 비교 근거): 초안(구도·비유 배치, gemini-4-hydrogen-medium · 2026-11-14 Flash 3.8 대체) → 내용 편집(비유·요소 대응·인과·사실 대조, gpt-6-luna high) → 시각 마감(정렬·그리기 순서·라벨·강조 색·움직임, claude-sonnet-5-5 medium) · 위치 제안은 내용 담당 모델 · 층별 `AIN_FIGURE_AI_<PLAN|DRAFT|CONTENT|VISUAL>`로 교체 · 앞 층 SVG는 작업 폴더 파일(`input-<id>.svg`)과 메모(`notes`)로 넘기고 상태에는 `figure.pass`·`figure.drafts`만, 사람 확인은 마지막 층 뒤 한 번 · 스킬은 provider 공통 원본 `~/.codex/skills`를 각 provider 경로에 심링크(Claude `~/.claude/skills`, agy `~/.gemini/config/skills`) · 이 단계만 작업 폴더 안 도구 사용 허용 · 스킬 불러오기 실패는 생성 실패 · `figure_plan`은 도구 금지 유지 · 제한 시간 층마다 60분(실행 한도 = 층 수 × 60분) · SVG는 작업 폴더 파일로 내고 응답엔 절대 경로(`svgFile`)만, 어댑터가 AI 작업 루트 안 파일만 읽어 같은 검사 적용(응답 앞 확인용 메모·첨부는 무시하고 마지막 결과 블록만) · 상한 400,000자
  - 검수 권한: 시각자료 요청·선택·확인·제외는 사람만(에이전트 403) · ADR-0006과 같은 원칙
- 책임: 생성 `automation/paseo/`(담당 illustrator·프롬프트·결과 계약) · 전이 `automation/n8n/`(기존 전달·대기 루프 그대로, 사람 결정에서 멈춤) · 배치·확인 상태 저장 `automation/editorial/`(domain/figures)
- 용어: 화면 '시각자료' · 코드·계약 `figure`
- 비용: 상태 3개·사람 결정 2회 추가 · 시각자료를 쓰지 않는 글은 변화 없음
- 관련: FLOW-002 · EDIT-001 FIGURE-001 · ADR-0006 · ADR-0010 · 내보내기 ADR-0012
