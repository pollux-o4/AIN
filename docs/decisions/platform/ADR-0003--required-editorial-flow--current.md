# ADR-0003 · 필수 단계와 명시적 보완

- 맥락: FLOW-001의 필수 8단계와 기존 축약 실행·revision 승계가 불일치
- 선택: 정확한 전체 plan·현재 revision 선행 결과 검증을 순수 상태 머신에서 강제 · 서비스·원시 n8n·TXT 인계가 같은 검사 사용
- 기존 데이터: 조회 시 변경·자동 재실행 없음 · 사용자 보완 요청이 이전 원고를 이력에 보존하고 새 revision 시작 · 중단 확인 전 pending 교체 금지
- 수정: 재검증한 선행 산출물만 원 revision 추적과 함께 승계 · 수정 위치 이후 결과·만족·승인 무효화
- 대안: 축약 허용 유지 / 기존 상태 자동 덮어쓰기 / 명시적 보완 · 마지막 선택으로 작업·비용·원문 보존
- 실행 한도: 8단계와 라우팅 1회를 수용 · 재연결은 예산 초기화 안 함 · 기한·중단 확인 유지
- 경계: 글 준비·사용자 만족·발행 준비 승인은 연결, 실제 발행은 별도
