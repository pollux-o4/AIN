# ADR-0005 · 에이전트는 HTTP 계약을 따르는 CLI로 접근한다

- 맥락: 사용자는 주로 대화형 AI와 함께 일하므로 AI가 사용자 대신 AIN에 의뢰·수정·삭제를 요청할 수 있어야 하지만, 기존 API는 화면 쿠키와 같은 출처 요청만 허용한다.
- 대안: 화면 자동 조작, 별도 기능을 가진 CLI, 화면과 같은 HTTP 계약만 전달하는 단순 CLI를 검토하였다.
- 선택: 화면과 같은 HTTP 계약을 따르는 단순 CLI와 별도 로컬 에이전트 토큰을 택한다. 사용 절차는 스킬에 둔다.
- 이유:
  - 텍스트 결과로 즉시 판단할 수 있고 화면 배치 변경에 영향을 받지 않는다.
  - 정책이 서버 한 곳에 있어 화면과 CLI가 같은 규칙을 따른다.
  - 화면 조작은 느리고 비용과 실패 부담이 크다.
- 결과:
  - cli 모듈은 contracts에만 의존한다(dependency-cruiser).
  - 새 기능은 서버 계약에 먼저 추가한다.
  - 화면은 사람 관찰과 E2E 검증 용도로 둔다.
- 관련: AGENT-001, AIN-API-001, ARCH-001
