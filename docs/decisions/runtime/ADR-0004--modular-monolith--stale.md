# ADR-0004 · 단일 정책 진입점과 단순 전달 경로

- 맥락: 기본 n8n은 이미 전달과 대기만 맡고 있으나, 기존 고급 워크플로에는 도메인 규칙과 예산이 들어 있고 상태 머신도 n8n 쪽에 있어 책임이 섞여 있었다.
- 선택:
  - 편집 도메인과 애플리케이션을 단일 정책 경로로 둔다.
  - n8n에서 도메인 코드 포함과 원시 상태 구조 실행을 제거한다.
  - 모든 실행 검증이 같은 편집 모듈을 사용한다.
- 모듈: editorial, paseo, n8n, contracts를 모듈로 나누고, runtime은 별도 배포 서비스가 아니라 같은 Node 프로세스의 조립 진입점으로 둔다.
- 경계: ARCH-001에 따라 공개 모듈 진입점과 주입 포트를 사용한다. UI와 어댑터의 정책 복제, 역방향 참조, 순환 참조는 검사기로 차단한다.
- 호환성:
  - 공개 사용자 입력, 조회, 명령, TXT 다운로드, 기존 SQLite, 작업 파일은 그대로 유지한다.
  - 이전 내부 /jobs, /exports, /providers HTTP 경로는 410으로 응답하고, 제공자 조회에는 공통 SDK CLI를 사용한다.
- n8n: 기존 기본 workflow ID는 유지하되, 이전 고급 JSON과 생성 정책은 제거한다. 기존 비공개 실행 증거는 보존한다.
- 검증: 같은 애플리케이션을 단위, 격리 n8n, fixture, 브라우저, 실제 모델로 확인한다. 실제 게시는 하지 않는다.
