# ADR-0001 · 독립 실행과 단방향 의존

- 맥락: 자동화를 독립적으로 운영하면서 ADR, C4, 규칙을 적용해야 한다.
- 대안: 소비 제품 내부 모듈, 공용 폴더 직접 import, 독립 CLI와 로컬 서비스, 별도 원격 플랫폼 방안을 검토하였다.
- 선택: 독립 저장소에 두고 mise로 실행하는 로컬 서비스 방식을 택한다. 설치 위치와 결과 이용은 호출자가 책임진다.
- 이유: 소비 제품 없이도 설치하고 검증·복구할 수 있으며, 기존 비밀값과 초안을 보존하고 원격 운영 부담을 줄일 수 있다.
- 경계: 소비 제품을 import하거나 역호출하지 않으며, 소비 제품 경로도 설정하지 않는다. 공통 Paseo는 외부 실행 의존성으로 둔다.
- 저장: 소스, 설정, 테스트, 문서, 비공개 실행 데이터 전체를 이 저장소에서 직접 소유하며 복사본은 따로 두지 않는다.
- 호환성: 기존 articleId, revision, 작업 해시, n8n workflow ID, credential ID는 그대로 유지한다. 과거 실행 기록은 역사 자료로 남긴다.
- 결과: 모델, 흐름, 문서, 데이터 변경은 AIN이 맡고, 호출 제품은 공개 계약만 사용한다.
