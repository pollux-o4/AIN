# AIN 글쓰기 대행

사용자 대신 AIN을 조작한다. 통로는 `mise run ain -- <명령>` (계약 AGENT-001). 화면(/write/)은 사용자가 진행을 보고 싶다고 할 때만 브라우저로 연다.

## 준비

- `mise run ain -- list`가 연결 오류면 `mise run editorial:start`로 기동해도 되는지 묻는다. 상태는 `mise run editorial:status`.

## 의뢰

1. 대화에서 글감·원하는 결과·독자·글 성격을 정리한다. 모호하면 한 번에 묻고, 정할 근거가 없으면 `auto`로 둔다.
   - mode: explain(설명)·procedure(따라 하기)·argue(주장)·narrate(이야기)·auto
   - level: beginner·intermediate·expert·auto
2. 사용자가 준 원문·확인한 사실은 파일로 저장해 `--source-file`로 넘긴다. 링크만으로는 원문을 읽지 않는다.
3. `new`는 AI 비용이 든다. 정리한 의뢰 내용을 보여 주고 승인 후 실행한다.
4. `wait <id>`는 백그라운드로 실행하고 종료 시 결과를 확인한다. 폴링하지 않는다.

## 편집장 (ADR-0006)

AIN 내부가 편집 메모·합격 판정·분량 가드로 먼저 루프를 돈다(ADR-0008). 에이전트는 그 뒤 결과를 보고 추가 지시하는 조언자다. 결과의 `brief`(수정 해석)가 의도와 다르면 그 차이부터 바로잡는다. 최종 검수(만족·발행 승인)는 사람만 한다.
사용자가 수정 요청하면 `status`가 `awaiting_brief`(수정 해석 확인 대기)에서 멈춘다. 에이전트가 `brief`를 원래 요구·피드백과 대조해 검토한다(ADR-0010). 맞으면 `approve-brief`로 착수, 어긋나면 `revise-brief <보정 의견>`. 판단 근거를 사용자에게 짧게 보고한다.

- 위임 범위: 의뢰 시 사용자에게 수정 상한을 확인한다(기본·서버 상한 2회). 범위 안 `feedback`은 매회 승인받지 않는다.
- 판정 근거: 사용자 요구(분량·독자·목적) 대비 `show --text` 본문 · review `findings` · `history`. 수치는 AIN 코드 지표만 인용하고 추정하지 않는다.
- 되돌림 조건: 요구 위반(분량 ±20% 밖, 독자 수준·목적 이탈) · 사실 오류·근거 없는 단정 · 구조 문제(도입 지도 없음, 구간 다중 개념). 문체 취향은 되돌리지 않는다.
- 지시 작성: 한 번에 모든 문제를 위치(절·표현)·바꿀 방향·유지할 것으로 적는다. 같은 지적이 두 번 해결되지 않으면 멈추고 보고한다.
- 넘김: 되돌림 조건이 없거나 상한(409)에 닿으면 사용자에게 판정 요약과 남은 문제를 보고하고 만족 여부를 묻는다.

## 결과 보고

- `status`·`label`·`issue`·`findings`를 근거로 실제 상태만 보고한다. AI 검토 통과를 만족·발행 승인으로 표현하지 않는다.
- 본문은 요약하고, 전문은 요청 시 `show <id> --text` 또는 `download`. 그림 포함 결과는 `export <id> --format html|zip --out <파일>`(확인한 시각자료만 포함).
- `issue`가 있으면 내용과 가능한 동작(`can`)을 알려 주고 사용자 결정을 받는다.

## 후속 동작

| 사용자 의도 | 명령 | 확인 |
| --- | --- | --- |
| 고쳐 달라 | `feedback <id> <구체적 수정 내용>` | AI 비용 · 수정 내용 확인 후 (편집장 위임 범위 안은 생략) |
| 멈춰 | `pause <id>` | 즉시 |
| 이어서 | `resume <id>` | AI 비용 |
| 보완 필요 표시 | `complete-requirements <id>` | AI 비용 |
| 이대로 좋다 | 사용자가 화면에서 확정 | 에이전트 요청은 서버가 403 |
| 발행 준비 승인 | 사용자가 화면에서 승인 | 에이전트 요청은 서버가 403 |
| 지워 | `delete <id>` | 제목 보여 주고 확인 · 진행 중이면 먼저 pause |

- 409는 다른 곳에서 바뀐 것: `show`로 최신 상태를 보고 다시 판단한다.
- 실제 발행은 AIN 범위 밖이다.
